## 2. Prompts, Parser, and Metrics (`F1`, `F2`, `F4`, `F9`)
All three prompt templates are pinned in `manuscript/ken/ken_dvqa_pilot/prompts.json` (sha256 `c8fb51d993cc123c21c120868ef8eb7b9a760ab9adf8ee6293ba2360ce28e854`):
- **QA Prompt (`PROMPT_QPA`, `F1` — `DirectAnswer QP-A`, App. C.1 of `manuscript/ken/guides/DrivingVQA_2025_2501.04671.pdf`; `max_new_tokens = 16`, sha256 `6321df1eca893c2f45bf0a7c49648b2134e14c2fb731bae3096e8a0dd69ba1f5`, `manuscript/ken/ken_dvqa_pilot/prompts.json :: qa_direct_prompt.template_sha256`):**
```text
Unless explicitly stated otherwise, assume you are driving a car in France.
Select all correct answers to the following question from the available options. Provide only the letters corresponding to your answer in the format: 'Answer(s): <letters>'
Question: {question}
Options: {options}
```
  *(For paired questions, `{question}` joins the two strings with `" | "`; `{options}` formats keys in sorted order `A..D` as `"{A: ..., B: ...}"`.)*
- **P3 Step-1 Caption Prompt (`PROMPT_CAP`, `F2`; image only, no question/options, `max_new_tokens = 60`, sha256 `8354e25cd84b4b81b9f60f79944b58edc0cde7b7a6200dec7a4a5a9c3e83a5b1`, `manuscript/ken/ken_dvqa_pilot/prompts.json :: p3_caption_prompt.template_sha256`):**
```text
Describe this driving scene objectively in 2 to 3 concise English sentences, focusing on road signs, traffic lights, lane markings, mirrors, vehicles, and pedestrians. Do not speculate.
```
- **P3 Step-2 Text-Only QA Prompt (`PROMPT_QPA_CAP`, `F2`; no image, `max_new_tokens = 16`, sha256 `59dd04fbb0e42537622ab919738469f00c7444b94cdb931b35e453e131a85d51`, `manuscript/ken/ken_dvqa_pilot/prompts.json :: p3_qa_from_caption_prompt.template_sha256`):** Prepends `Scene description: {caption}\n` verbatim to `PROMPT_QPA`.
- **Parser & Unparseable Stop Rule (`F1`, `manuscript/ken/ken_dvqa_pilot/score.py`):** Take the last line matching `(?i)Answer\(s\)\s*:\s*(.+)` and extract distinct uppercase letters in the item's option set $\mathcal{O}_i \subseteq \{\text{A, B, C, D}\}$. If no match or no valid letter in $\mathcal{O}_i$ is found, the item is marked `unparseable` and receives $\hat{Y}_i = \emptyset$ ($\text{Exam}_i = 0, \text{F1}_i = 0$). **If `unparseable_rate > 10.0%` in any arm $\times$ backbone cell, or if `> 20.0%` of `P3` captions are empty, `JOB STOP` for diagnosis with no verdict.**
- **Metrics (local, CPU, points $\times 100$):** With ground-truth $Y_i \subseteq \mathcal{O}_i$ (`true_answers`):
  $$\text{Exam}_i = 100 \cdot \mathbb{I}[\hat{Y}_i = Y_i], \qquad \text{F1}_i = 100 \cdot \frac{2\,|\hat{Y}_i \cap Y_i|}{|\hat{Y}_i| + |Y_i|} \;\;(\text{0 if } \hat{Y}_i = \emptyset)$$
- **Bootstrap (`F4`, `F9`):** Reported for every arm $\times$ backbone and **pooled** ($\Delta_i^{\text{pool}} = \frac{1}{2}(\Delta_{i,\text{Qwen}} + \Delta_{i,\text{InternVL3}})$). Paired image bootstrap, **`B = 10,000` draws**, `np.random.default_rng(0)`, one index matrix `(10000, 1000)` (digest `3997f6fc69540d05d47b5bfcedc64906e76e383971644d6592e5ad3ea364ee18`) for `P1`/`P2` and `(10000, 500)` (digest `c15746075d15086dcd17f5b910875d6fe4007dfc0cfbb760e2823250448b188c`) for `P3`, 95% percentile CI `[2.5%, 97.5%]`. `P1` is also reported on the $K_i \ge 1$ subset ($n=974$, `manuscript/ken/dvqa_train_descriptive_stats.json :: subsets.dev1000.k_ge_1_gold_box_samples`) as a non-deciding descriptive check (`F9`).

## 3. Experimental Arms and Frozen P2 Specification (`F6`)
- **`P1` (`dev1000`, $n=1,000$):**
  - `P1-Blind`: No image; `PROMPT_QPA` only.
  - `P1-Full`: Full image $I_i$ + `PROMPT_QPA`.
  - `P1-Oracle`: Full image $I_i$ + gold box crops $C_i^{\text{gold}}$ + `PROMPT_QPA` (no entity label strings). Each gold box $(x, y, w, h)$ is expanded by $50\%$ around its center and clipped to $(W_i, H_i)$: $x'_1=\max(0, x-0.25w)$, $y'_1=\max(0, y-0.25h)$, $x'_2=\min(W_i, x+1.25w)$, $y'_2=\min(H_i, y+1.25h)$, then resized to `448×448` (`BICUBIC`). (For $K_i=0$, $C_i^{\text{gold}}=\emptyset$.)
- **`P3` (`dev500`, $n=500$):** `P3-SelfCap` generates $\hat{c}_i$ via `PROMPT_CAP` on $I_i$, then answers via `PROMPT_QPA_CAP` with **no image**, compared against `P1-Full`'s first `500` rows (`dev500`).
- **`P2` (`dev1000`, $n=1,000$; runs ONLY if `P1` is GO, frozen now per `F6` in `manuscript/ken/ken_dvqa_pilot/decode.py`):**
  - `P2-Grid` (`AnyRes-4` baseline): Full image $I_i$ + `4` non-overlapping $2\times 2$ quadrant crops of $I_i$, each resized to **`448×448` pixels** ($K=4$ tiles).
  - `P2-AttCrop` (token-matched attention crops, $K=4$ tiles):
    1. **Attention source (`F6`):** With `attn_implementation="eager"`, extract cross-attention weights from all trailing prompt query token positions after the visual tokens to the $H_p \times W_p$ full-image visual patch tokens, averaged uniformly across all attention heads and middle-to-late decoder layers: **0-indexed layers `14..21` inclusive** (of `0..27`) for `Qwen2.5-VL-7B` @ `cc594898`, and **0-indexed layers `16..23` inclusive** (of `0..31`) for `InternVL3-8B-hf` @ `259a3b64`.
    2. **Window selection (`F6`):** Slide a window of size $\lceil 0.25 W_p \rceil \times \lceil 0.25 H_p \rceil$ with **stride `1` patch** over the 2D patch-attention map; score each window by its summed attention (deterministic tie-break by `(-score, row, col)`) and pick **$K=4$** windows via greedy NMS with **IoU threshold `0.3`**.
    3. **Expansion & tile resize (`F6`):** Map each window to pixel coordinates in $I_i$, apply the exact $50\%$ clipped box expansion above, and resize each of the $K=4$ crops to **`448×448` pixels** (`BICUBIC`, matching `P2-Grid` tile resolution and visual token count 1-to-1).

## 4. Decision Rules (`F7`, `F9`, `F12`)
- **P1:** **STOP (Shortcut)** if $\text{Exam}(\text{P1-Blind}) \ge \text{Exam}(\text{P1-Full}) - 5.0$ pts (pooled or either backbone). **GO (`P1`)** iff pooled $\Delta\text{Exam}_{\text{P1}} = \text{Exam}(\text{P1-Oracle}) - \text{Exam}(\text{P1-Full}) \ge +3.0$ pts — *anchored on Table 3's fine-tuned oracle-vs-predicted gain (`62.0` vs `58.7` in `manuscript/ken/guides/DrivingVQA_2025_2501.04671.pdf`), not a zero-shot oracle gain (`F7`)* — **and** its 95% CI lower bound $> 0$ (with no Shortcut STOP). Otherwise **STOP (`P1`)**, and **`P2` is cancelled with `0` GPU spent**.
- **P2 (gated on `P1 GO`):** With $\Delta\text{Exam}_{\text{P2-Grid}} = \text{Exam}(\text{P2-AttCrop}) - \text{Exam}(\text{P2-Grid})$ and $\rho_{\text{rec}} = \frac{\text{Exam}(\text{P2-AttCrop}) - \text{Exam}(\text{P1-Full})}{\text{Exam}(\text{P1-Oracle}) - \text{Exam}(\text{P1-Full})}$, **GO (`P2`)** iff pooled $\Delta\text{Exam}_{\text{P2-Grid}}$ has 95% CI lower bound $> 0$ **and** pooled $\rho_{\text{rec}} \ge 0.50$. Otherwise **STOP (`P2`)**.
- **P3:** **GO (`P3`)** iff $\Delta\text{Exam}_{\text{P3},m} = \text{Exam}_m(\text{P1-Full}) - \text{Exam}_m(\text{P3-SelfCap}) \ge +10.0$ pts **and** 95% CI lower bound $> 0$ **on BOTH backbones** ($n=500$). Otherwise **STOP (`P3`)**.
- **Related baselines for any post-GO discussion (`.session_backup/2026-10-13/decisions/CC-104.txt` l.125):** `ViCrop` (`manuscript/ken/guides/ViCrop_2025_2502.17422.pdf`), `ZoomEye` (`manuscript/ken/guides/ZoomEye_2024_2411.16044.pdf`), and `RIV-CoT` (`manuscript/ken/guides/DrivingVQA_2025_2501.04671.pdf`). No unverified positioning claim is made here.
