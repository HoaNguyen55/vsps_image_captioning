## 2. Prompts, Parser Grammar (`CC-104a W1`), and Metrics (`F1`, `F2`, `F4`, `F9`)
All three prompt templates are pinned in `manuscript/ken/ken_dvqa_pilot_v3/prompts.json` (sha256 `712d9a3a427d5b5797e03db8695c6fe531273b799862df9bcd6455b3605841cf`):
- **QA Prompt (`PROMPT_QPA`, `F1` — adapted from App. C.1 of `manuscript/ken/guides/DrivingVQA_2025_2501.04671.pdf` by removing the CoT reasoning sentence and changing `"Then, provide"` to `"Provide only"`; `max_new_tokens = 16`, sha256 `6321df1eca893c2f45bf0a7c49648b2134e14c2fb731bae3096e8a0dd69ba1f5`, `manuscript/ken/ken_dvqa_pilot_v3/prompts.json :: qa_direct_prompt.template_sha256`):**
```text
Unless explicitly stated otherwise, assume you are driving a car in France.
Select all correct answers to the following question from the available options. Provide only the letters corresponding to your answer in the format: 'Answer(s): <letters>'
Question: {question}
Options: {options}
```
  *(For paired questions, `{question}` joins the two strings with `" | "`; `{options}` formats keys in sorted order `A..D` as `"{A: ..., B: ...}"`.)*
- **P3 Step-1 Caption Prompt (`PROMPT_CAP`, `F2`; image only, no question/options, `max_new_tokens = 60`, sha256 `8354e25cd84b4b81b9f60f79944b58edc0cde7b7a6200dec7a4a5a9c3e83a5b1`, `manuscript/ken/ken_dvqa_pilot_v3/prompts.json :: p3_caption_prompt.template_sha256`):**
```text
Describe this driving scene objectively in 2 to 3 concise English sentences, focusing on road signs, traffic lights, lane markings, mirrors, vehicles, and pedestrians. Do not speculate.
```
- **P3 Step-2 Text-Only QA Prompt (`PROMPT_QPA_CAP`, `F2`; no image, `max_new_tokens = 16`, sha256 `59dd04fbb0e42537622ab919738469f00c7444b94cdb931b35e453e131a85d51`, `manuscript/ken/ken_dvqa_pilot_v3/prompts.json :: p3_qa_from_caption_prompt.template_sha256`):** Prepends `Scene description: {caption}\n` verbatim to `PROMPT_QPA`.
- **Parser Grammar & Unparseable Stop Rule (`CC-104a W1`, `manuscript/ken/ken_dvqa_pilot_v3/score.py`):** Take the substring after the last line matching `(?i)Answer\(s\)\s*:\s*(.*)`. Without calling `.upper()`, parse a leading list of uppercase option tokens `A..D` separated by `','`, `', and'`, `'and'`, `'&'`, `'/'`, `';'`, or whitespace, or a run of `2–4` distinct uppercase option letters (`'AC'` $\to$ `['A','C']`). A capital letter `A..D` followed by a space and a lowercase word (`[A-D]\s+[a-z]`, e.g. `'B, A car is coming'`) ends the option list before that capital so prose articles are not misparsed as options (`'B, A car is coming'` $\to$ `['B']`; `'B, because a car'` $\to$ `['B']`). After the option list, if any standalone `A..D` token remains in the tail, or `'or'` or `'.'` separates option letters (`'A or B'`, `'A. B.'`), or any parsed letter lies outside the item's valid option set $\mathcal{O}_i \subseteq \{\text{A, B, C, D}\}$ (`'A, E'`, or `'A, C'` when $\mathcal{O}_i=\{\text{A, B}\}$), the item is marked `unparseable` ($\hat{Y}_i = \emptyset$, $\text{Exam}_i = 0, \text{F1}_i = 0$). `manuscript/ken/ken_dvqa_pilot_v3/score.py` logs per-cell counts of each unparseable reason in `unparseable_reasons` (`empty_text`, `missing_answer_prefix`, `empty_after_prefix`, `lowercase_only_after_prefix`, `no_leading_option_list`, `or_between_letters`, `dot_between_letters`, `duplicate_compact_letters`, `out_of_option_set`, `trailing_standalone_option_token`). **If `unparseable_rate > 10.0%` in any arm $\times$ backbone cell, or if `> 20.0%` of `P3` captions are empty, `JOB STOP` for diagnosis with no verdict.**
- **Metrics & Bootstrap (`F4`, `F9`):** With ground-truth $Y_i \subseteq \mathcal{O}_i$: $\text{Exam}_i = 100 \cdot \mathbb{I}[\hat{Y}_i = Y_i]$ and $\text{F1}_i = 100 \cdot \frac{2\,|\hat{Y}_i \cap Y_i|}{|\hat{Y}_i| + |Y_i|}$ (`0` if $\hat{Y}_i = \emptyset$). Reported for every arm $\times$ backbone and **pooled** ($\Delta_i^{\text{pool}} = \frac{1}{2}(\Delta_{i,\text{Qwen}} + \Delta_{i,\text{InternVL3}})$). Paired image bootstrap, **`B = 10,000` draws**, `np.random.default_rng(0)`, one index matrix `(10000, 1000)` (digest `3997f6fc69540d05d47b5bfcedc64906e76e383971644d6592e5ad3ea364ee18`) for `P1`/`P2` and `(10000, 500)` (digest `c15746075d15086dcd17f5b910875d6fe4007dfc0cfbb760e2823250448b188c`) for `P3`, 95% percentile CI `[2.5%, 97.5%]`. All decision thresholds in `manuscript/ken/ken_dvqa_pilot_v3/decide.py` are evaluated on **unrounded** floats before rounding for JSON display, and every output status (`COMPLETE`, `INCOMPLETE`, `JOB_STOP_*`) includes the per-cell table and the non-deciding $K_i \ge 1$ subset check ($n=974$, `manuscript/ken/dvqa_train_descriptive_stats_v2.json :: subsets.dev1000.k_ge_1_gold_box_samples`).

## 3. Experimental Arms and Frozen P2 Specification (`F6`, `CC-104a W9`)
- **`P1` (`dev1000`, $n=1,000$):** `P1-Blind` (no image; `PROMPT_QPA` only); `P1-Full` (full image $I_i$ + `PROMPT_QPA`); `P1-Oracle` (full image $I_i$ + gold box crops $C_i^{\text{gold}}$ + `PROMPT_QPA` without entity label strings; each gold box $(x, y, w, h)$ expanded by $50\%$ around its center, clipped to $(W_i, H_i)$, and resized to `448×448` `BICUBIC`; $C_i^{\text{gold}}=\emptyset$ when $K_i=0$).
- **`P3` (`dev500`, $n=500$):** `P3-SelfCap` generates $\hat{c}_i$ via `PROMPT_CAP` on $I_i$, then answers via `PROMPT_QPA_CAP` with **no image**, compared against `P1-Full`'s first `500` rows (`dev500`).
- **`P2` (`dev1000`, $n=1,000$; runs ONLY if `P1` is GO, frozen per `F6` in `manuscript/ken/ken_dvqa_pilot_v3/decode.py`):**
  - `P2-Grid` (`AnyRes-4` baseline): Full image $I_i$ + `4` non-overlapping $2\times 2$ quadrant crops of $I_i$, each resized to **`448×448` pixels** ($K=4$ tiles).
  - `P2-AttCrop` (token-matched attention crops, $K=4$ tiles):
    1. **Attention source & layer indices (`CC-104a W9`):** With `attn_implementation="eager"`, extract cross-attention weights from all trailing prompt query token positions after the visual tokens to the $H_p \times W_p$ full-image visual patch tokens, averaged uniformly across all attention heads and middle-to-late decoder layers: **0-indexed layers `14..21` inclusive** (of `0..27`, `num_hidden_layers = 28`) for `Qwen2.5-VL-7B` @ `cc594898` (where $H_p, W_p$ come directly from `image_grid_thw` divided by `merge_size = 2`), and **0-indexed layers `16..23` inclusive** (of `0..27`, `text_config.num_hidden_layers = 28`, verified at <https://huggingface.co/OpenGVLab/InternVL3-8B-hf/resolve/259a3b64a14623c0ec91a045cb43f7c5af5fa6af/config.json>, sha256 `2f651cf5dcad81635fcd688dc8aa569797a3d829b9d0644f489e1c7272b1c637`) for `InternVL3-8B-hf` @ `259a3b64`. At revision `259a3b64`, `InternVL3-8B-hf`'s preprocessor configuration (<https://huggingface.co/OpenGVLab/InternVL3-8B-hf/resolve/259a3b64a14623c0ec91a045cb43f7c5af5fa6af/preprocessor_config.json>, sha256 `af09ffbe57900d5ae07f93f4c20693559a272e32fa6c5f816132cb71985aac98`) sets `"crop_to_patches": false` and `"size": {"height": 448, "width": 448}`, compressing the full image into a single `448×448` tile with a **`16×16` patch grid (`256` visual tokens, `image_seq_length = 256`, `image_token_id = 151667`)**.
    2. **Zero silent fallbacks:** `manuscript/ken/ken_dvqa_pilot_v3/decode.py` forbids uniform fallback maps, `math.isqrt` reshapes, or default grid substitutions. If `len(vis_indices) != H_p * W_p`, `query_indices` is empty, or `len(out.attentions) != 28`, `manuscript/ken/ken_dvqa_pilot_v3/decode.py` raises `RuntimeError("JOB_STOP_P2_ATTENTION_GRID_MISMATCH: ...")` and halts the job immediately.
    3. **Window selection & deterministic NMS padding rule:** Slide a window of size $\lceil 0.25 W_p \rceil \times \lceil 0.25 H_p \rceil$ with **stride `1` patch** over the 2D patch-attention map; score each window by its summed attention (tie-break by `(-score, row, col)`) and pick **$K=4$** windows via greedy NMS with **IoU threshold `0.3`**. If greedy NMS yields fewer than `4` windows, fill the remaining slots in deterministic `(-score, row, col)` order from the NMS-deferred windows, and then with the full image $[0, 0, W_i, H_i]$ if total candidate windows $< 4$. Expand each of the `4` boxes by $50\%$ (clipped to $W_i \times H_i$) and resize to **`448×448` pixels** (`BICUBIC`).

## 4. Decision Rules (`F7`, `F9`, `F12`)
- **P1:** **STOP (Shortcut)** if $\text{Exam}(\text{P1-Full}) - \text{Exam}(\text{P1-Blind}) \le 5.0$ pts **either pooled OR on either individual backbone** *(explicitly stricter than pooled-only)*. **GO (`P1`)** iff pooled $\Delta\text{Exam}_{\text{P1}} = \text{Exam}(\text{P1-Oracle}) - \text{Exam}(\text{P1-Full}) \ge +3.0$ pts — *anchored on Table 3's fine-tuned oracle-vs-predicted gain (`62.0` vs `58.7` in `manuscript/ken/guides/DrivingVQA_2025_2501.04671.pdf`, `manuscript/ken/dvqa_train_descriptive_stats_v2.json :: published_paper_anchors_2501_04671`), not a zero-shot oracle gain (`F7`)* — **and** its 95% CI lower bound $> 0$ (with no Shortcut STOP). Otherwise **STOP (`P1`)**, and **`P2` is cancelled with `0` GPU spent**.
- **P2 (gated on `P1 GO`):** With $\Delta\text{Exam}_{\text{P2-Grid}} = \text{Exam}(\text{P2-AttCrop}) - \text{Exam}(\text{P2-Grid})$ and $\rho_{\text{rec}} = \frac{\text{Exam}(\text{P2-AttCrop}) - \text{Exam}(\text{P1-Full})}{\text{Exam}(\text{P1-Oracle}) - \text{Exam}(\text{P1-Full})}$, **GO (`P2`)** iff pooled $\Delta\text{Exam}_{\text{P2-Grid}}$ has 95% CI lower bound $> 0$ **and** pooled $\rho_{\text{rec}} \ge 0.50$. Otherwise **STOP (`P2`)**.
- **P3:** **GO (`P3`)** iff $\Delta\text{Exam}_{\text{P3},m} = \text{Exam}_m(\text{P1-Full}) - \text{Exam}_m(\text{P3-SelfCap}) \ge +10.0$ pts **and** 95% CI lower bound $> 0$ **on BOTH backbones** ($n=500$). Otherwise **STOP (`P3`)**.
- **Related baselines for any post-GO discussion (`.session_backup/2026-10-13/decisions/CC-104.txt` l.125):** `ViCrop` (`manuscript/ken/guides/ViCrop_2025_2502.17422.pdf`), `ZoomEye` (`manuscript/ken/guides/ZoomEye_2024_2411.16044.pdf`), and `RIV-CoT` (`manuscript/ken/guides/DrivingVQA_2025_2501.04671.pdf`).
