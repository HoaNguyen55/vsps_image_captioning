Claims that a captioning model or a large vision-language model (LVLM) "hallucinates less" rest mostly on object-level scores such as CHAIR (Rohrbach et al., 2018) and object F1, which compare the objects a caption names with a gold set (Section 2). Like any quality measure, these scores can respond to the instrument, not the model. This registered measurement audit asks when an object-level score supports a comparison between two systems. It tests gold completeness, object count and reference exchangeability on fixed system outputs, and reports every registered verdict, failures included (Table 1).<!-- CC-088 A-3: paper type -->

**A quality-assessment question.** For readers of image-quality and caption-metric work this has a familiar form: the validity of a quality measure can depend on its reference set. González-Chávez et al. (2024) ask whether image-captioning metrics measure what they should; we ask the same of object-level hallucination scores, whose reference set is the gold. If the sign of a score's verbosity slope is a property of the gold, reporting the gold is part of reporting the measure (Section 8.4).<!-- rev1 (item 12g): SPIC fit paragraph brought forward from §9.4; gonzalezchavez2024metrics (SPIC 120:117071), positioning per title as in §2; no new number -->

Prior work controls length or reports aggregates (Wei et al., 2024; Fazli et al., 2026); we fix the number of mentioned objects per image. **Why Vietnamese.** Vietnamese is a low-resource language for image captioning, and that is what makes it a good test bed for incomplete gold. Its human-written caption sets are small: UIT-ViIC holds 19,250 captions for 3,850 COCO images (Lam et al., 2020) and KTVIC 21,635 captions for 4,327 images (Pham et al., 2024), while the COCO caption set was described with over 1.5 million English captions for over 330,000 images (Chen et al., 2015). The authors of UIT-OpenViIC present their set as a contribution to the low-resource research community in Vietnam (Bui et al., 2026). With two or three Vietnamese references per Crossmodal-3600 image (Section 6.2), reference gold is incomplete by construction, so the question this paper asks is sharper for Vietnamese than for English benchmarks with five or fifty references.<!-- src: counts from the arXiv abstracts, checked 2026-10-29 via export.arxiv.org: lam2020uit arXiv 2002.00175 ("UIT-ViIC consists of 19,250 Vietnamese captions for 3,850 images"); pham2024ktvic arXiv 2401.08100 ("4,327 images and 21,635 Vietnamese captions"); chen2015microsoft arXiv 1504.00325 ("over one and a half million captions describing over 330,000 images"); bui2026uit per the arXiv preprint 2305.04166 abstract ("To contribute to the low-resources research community as in Vietnam"); 2-3 references = sec7 §7.2 (xm3600_full_verdict.json) -->

## 1.1 Research questions

- **RQ1 (gold completeness; registered).** Is object F1's slope on log object count ordered by gold completeness, and which parts of its behaviour are not predicted? (Sections 4, 5 and 6)
- **RQ2 (count; exploratory).** How many published precision gains survive when both captions name the same number of objects on every image, and how does the answer depend on the control? (Section 3.3 and Supplementary S3)
- **RQ3 (human judgments and preference data; registered).** Do existing human judgments penalize object count, does a count-controlled score track them better than the raw score, and does the count channel enter public preference data? (Section 7)

**Contributions.** Prior validity work asks whether caption metrics and hallucination benchmarks measure what they should (Section 2); we ask how the answer for object-level scores depends on the gold, and treat the gold as the experimental factor.

1. A registered out-of-sample test on XM3600, repeated with a second backbone on the same images, that object F1's verbosity slope is ordered by gold completeness, and a registered 50-reference replication on PASCAL-50S whose primary prediction (P50-A4) failed at the label-gold step while the slope rose at every registered reference level (P50-O2, secondary), with the other failed predictions and the post hoc checks that bound them (Sections 4 and 6).
2. Per-image count-matched controls that apply to other groups' released captions, with a specification curve over 15 published comparisons<!-- src: .session_backup/2026-10-13/r10_cpu/e1_x1pb_verification_v2.json :: overview_15_pairs.n_pairs --> (post hoc; Section 3.3 and Supplementary S3).
3. Registered tests of the count channel in public human judgments and preference data (Section 7), and a reference-exchangeability diagnostic (Section 5).
4. For authors and reviewers: a registration ledger (Table 1 and Supplementary Table S4.0), a reporting checklist (Section 8.3) and a numbers manifest that ties each reported value to a stored result (Section 3.6).<!-- pass 2: old §1.2 list condensed to one paragraph; §1.3 renumbered 1.2. pass 3 (2026-10-28): contributions as a numbered list with the positioning sentence (scorecard: novelty legibility, writing); no new number -->
