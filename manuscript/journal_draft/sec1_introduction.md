Claims that a captioning model or a large vision-language model (LVLM) "hallucinates less" rest mostly on object-level scores such as CHAIR (Rohrbach et al., 2018) and object F1, which compare the objects a caption names with a gold set (Section 2). They are reference-based quality measures of a visual description, and their reference is the gold; like any quality measure, they can respond to the instrument, not the model.<!-- rev2 (CC-181 W8 / plan T2): SPIC framing, wording only; no new claim or citation --> This registered measurement audit asks when an object-level score supports a comparison between two systems. It tests gold completeness, object count and reference exchangeability on fixed system outputs, and reports every registered verdict, failures included (Table 1).<!-- CC-088 A-3: paper type -->

**Gold completeness.** One reference names only the most salient objects, five name more, and instance labels name objects no writer mentions. On the 5,000 COCO Karpathy-test images and 9 systems (exploratory; Section 6.1), the slope of object F1 on the log number of mentioned objects is −4.77 [−6.10, −3.54] with one reference, +10.57 [+9.70, +11.43] with five and +22.13 [+21.39, +22.89] with instance labels, so two systems can be ranked in opposite orders under two golds.<!-- src: .session_backup/2026-10-26/a_full5000/out/r4_full5000_all9.json (sha256 332da8b6264c) :: n_img = 5000, systems (9 entries); r4 = 9 systems x 5,000 (FILL_RULE, PI-1026c) --><!-- src: .session_backup/2026-10-26/a_full5000/out/r4_full5000_all9.json (sha256 332da8b6264c) :: gold.refs1_randk.slope, slope_ci; r4 = 9 systems x 5,000 (FILL_RULE, PI-1026c) --><!-- src: same :: gold.refs5_randk.slope, slope_ci --><!-- src: same r4 file :: gold.inst.slope, slope_ci --><!-- rev2 (CC-181 W8): condensed; original paragraph moved verbatim to Supplementary S10 -->

**A quality-assessment question.** González-Chávez et al. (2024) ask whether image-captioning metrics measure what they should; we ask the same of object-level hallucination scores, whose reference set is the gold. If the sign of a score's verbosity slope is a property of the gold, reporting the gold is part of reporting the measure (Section 8.4).<!-- rev1 (item 12g): gonzalezchavez2024metrics (SPIC 120:117071), positioning per title as in §2; rev2: first sentence folded into the opening paragraph -->

**The confirmatory claim.** Our one confirmatory claim is that object F1's verbosity slope is **ordered by gold completeness**. It rests on a registered test on 600 XM3600 images with human-verified Open Images labels (Section 6.2) and a registered second-backbone test (Qwen3-VL-8B) on 537 of them (Section 6.3). Two post hoc qualifications are part of the claim: the positive label-gold sign depends on excluding mentions the labels cannot verify (Section 6.2), and the negative reference-gold slopes on XM3600 rest on one verbose system, without which the one-reference slope is +10.52 rather than −8.99 (Section 6.5). Because the reference golds are nested, their ordering is expected even under random missingness (Section 4.2); the risky step, label gold above every reference gold, passed on XM3600, passed on the second backbone although the post hoc lower bracket is +1.97 [−0.44, +4.01], and failed on PASCAL-50S (50 references, seven public LVLMs), where 50 references < VOC labels did not hold (−2.29 [−5.15, +0.61]; Section 6.4). Two of five XM3600 predictions failed, and nine registered predictions failed in all (Table 1); with 19 PASS-or-FAIL ledger rows, about 0.5 false PASSes would be expected by chance if each were an independent one-sided test at 2.5% (a rough guide). **Count (exploratory).** Because a model names its most reliable objects first, shortening can improve CHAIR without better object choice. Prior work controls length or reports aggregates (Wei et al., 2024; Fazli et al., 2026); we fix the number of mentioned objects per image. Applied post hoc to 15 published comparisons, it leaves between 2 and 6 of the 12 significant raw precision gains after Holm correction, depending on the control (Section 3.3). No count-control result is confirmatory: the registered count-matched leaderboard failed its fidelity check, and a planned confirmation found too few eligible pairs to run.<!-- src: .session_backup/2026-10-13/r10_cpu/e1_x1pb_verification_v2.json :: overview_15_pairs.mcp_prefix_survives_holm --><!-- src: same :: overview_15_pairs.mcp_rand_exact_survives_holm --><!-- src: same :: overview_15_pairs.raw_dP_sig_pos; '15' = overview_15_pairs.n_pairs --><!-- rev2 (CC-181 W8): condensed; original paragraph moved verbatim to Supplementary S10 -->

**Why Vietnamese.** Vietnamese is a low-resource language for image captioning: UIT-ViIC holds 19,250 captions for 3,850 COCO images (Lam et al., 2020) and KTVIC 21,635 captions for 4,327 images (Pham et al., 2024), against over 1.5 million English COCO captions (Chen et al., 2015). With two or three Vietnamese references per Crossmodal-3600 image (Section 6.2), reference gold is incomplete by construction, so the question is sharper for Vietnamese than for English benchmarks with five or fifty references.<!-- src: counts from the arXiv abstracts, checked 2026-10-29 via export.arxiv.org: lam2020uit arXiv 2002.00175; pham2024ktvic arXiv 2401.08100; chen2015microsoft arXiv 1504.00325 ('over one and a half million captions'); rev2: full paragraph (with the UIT-OpenViIC sentence) moved verbatim to Supplementary S10 -->

## 1.1 Research questions

- **RQ1 (gold completeness; registered).** Is object F1's slope on log object count ordered by gold completeness? (Sections 4–6)<!-- rev2 (CC-181 W8): condensed; original paragraph moved verbatim to Supplementary S10 -->
- **RQ2 (count; exploratory).** How many published precision gains survive an exact per-image count match, and how does the answer depend on the control? (Section 3.3)<!-- rev2 (CC-181 W8): condensed; original paragraph moved verbatim to Supplementary S10 -->
- **RQ3 (human judgments and preference data; registered).** Do human judgments and preference data carry the count channel, and does a count-controlled score track judgments better than the raw score? (Section 7)<!-- rev2 (CC-181 W8): condensed; original paragraph moved verbatim to Supplementary S10 -->

**Contributions.** We treat the gold as the experimental factor of object-level score validity (Section 2).<!-- rev2 (CC-181 W8): condensed; original paragraph moved verbatim to Supplementary S10 -->

1. A registered out-of-sample test on XM3600, repeated with a second backbone on the same images, that object F1's verbosity slope is ordered by gold completeness, and a registered 50-reference replication on PASCAL-50S whose primary prediction (P50-A4) failed at the label-gold step, with the post hoc checks that bound these results (Sections 4 and 6).
