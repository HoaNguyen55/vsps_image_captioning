# 1 Introduction

Claims that a captioning model or a large vision-language model (LVLM) "hallucinates less" rest mostly on object-level scores such as CHAIR (Rohrbach et al., 2018) and object F1, which compare the mentioned objects with a gold set (Section 2). Like any measurement, these scores can respond to properties of the instrument, not of the model. We ask when an object-level score supports a comparison between two systems, and study three properties of the measurement that bear on the answer: gold completeness, the number of objects a caption names, and the exchangeability of the references. It is the captioning form of a familiar problem in information retrieval, where incomplete relevance judgments bias evaluation measures (Buckley and Voorhees, 2004). The paper is a registered measurement audit: it tests these properties on fixed system outputs, reports every registered verdict, failures included, and labels each other analysis pre-specified, exploratory or post hoc.<!-- CC-088 A-3: paper type -->

**Count.** A caption that names fewer objects tends to have higher precision, because a model names its most reliable objects first, so a method that shortens captions, stops earlier or prunes uncertain mentions improves CHAIR without choosing objects better. The concern is not ours (LeHaCE, Wei et al., 2024; "risk suppression", Fazli et al., 2026; Section 2), but prior work controls length or reports aggregates. We add a per-image control that fixes the number of mentioned objects, reported across several controls; its application is exploratory, as the protocol was written after a pilot on the same outputs (Section 6.1). ## 1.1 Research questions

- **RQ1 (gold completeness).** Is object F1's slope on log object count ordered by gold completeness and positive under label gold, and which parts of the slope's behaviour are not predicted? (Sections 4 and 7)
- **RQ2 (count).** How many published precision gains survive when both captions name the same number of objects on every image, and how does the answer depend on the control? (Sections 3 and 6; the re-scoring is exploratory)
- **RQ3 (exchangeability).** Are the references of caption corpora exchangeable, and what breaks in reference-count analyses when they are not? (Sections 5 and 7.5)
- **RQ4 (human validity).** Do existing human judgments penalize object count, and does a count-controlled score track them better than the raw score? (Section 8)
- **RQ5 (preference data).** Does the count channel enter through public hallucination-preference data, even when the pairs are matched on length? (Section 9)
