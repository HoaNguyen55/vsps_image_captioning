## 6.3 Placebos and positive controls

**Registered seed placebo.** The placebo compares two sampling seeds of one model on the same images; a control that finds a "gain" there is miscalibrated. Under rules registered before any placebo output, a control is admissible if $|\Delta P| \le 0.5$ with an interval covering 0, and the first admissible control is primary (Supplementary S4). The prediction held: the matched prefix is admissible and was selected<!-- src: .session_backup/2026-10-13/decisions/PD-15.txt :: line 1-2 "K2 HELD with C* = matched_prefix" and item 1 "matched_prefix is admissible"; evaluator output .session_backup/2026-10-18/n9k2_scoring/k2/k2_scores.json (sha256 0f0e952e) :: C_STAR = matched_prefix, K2_PREDICTION = HELD; rule text manuscript/prereg/2026-10-18_e1_k2_placebo_addendum.md (b8b2500) §3 -->. The placebo was decoded in the leaderboard harness of Section 6.4, which failed its fidelity check. Its result therefore calibrates the control only: it is not evidence for any count-control claim, and it does not make the post hoc curve of Table 6.1 confirmatory.

**Positive control.** Removing the first hallucinated object from each baseline caption should raise precision at matched prefix by at least 3 points (fixed after the pilot); the control is underpowered at 500 images on 2 of 8 baselines<!-- src: .session_backup/2026-10-13/r10_cpu/e1_x1pb_verification_v2.json :: controls_K2_K3.registered_k3_en_summary.verdict = FAIL_UNDERPOWERED_ON_2_OF_8_BASELINES_AT_N500 -->, so the nulls of Table 6.1 are results at this sample size (Supplementary S3).<!-- src (A6.3 merge, VERIFIED): '8' (E1 K3 baselines) = .session_backup/2026-10-13/r10_cpu/e1_x1pb_verification_v2.json :: controls_K2_K3.registered_k3_en_summary.n_baselines -->
