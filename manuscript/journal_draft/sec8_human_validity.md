## 8.4 The object-count channel in preference data

If the chosen response of a preference pair tends to name fewer objects, a model trained on the pairs can learn to name fewer objects; we measure this in seven public sets, without testing trained models. Both responses are matched to COCO-80 with the CHAIR matcher; pairs with no COCO-80 class are dropped; a pair is *count-matched* if the chosen and rejected responses name the same number of classes. Among unmatched pairs we report the share where the chosen response names fewer classes (0.5 = no direction).

## 8.5 What the human evidence supports

The human results check, but do not ground, the measurement argument. Humans penalize object count on long captions (registered), which supports the confound, and are close to count-neutral on short COCO captions (exploratory); count-matched precision tracks them better in no set and worse in the registered test (Section 8.1); and span-label agreement does not rise to complete COCO-80 gold (registered).
