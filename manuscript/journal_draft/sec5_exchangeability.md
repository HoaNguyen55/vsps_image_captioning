Every analysis that varies the number of references rests on (A1), yet caption datasets rarely document it.

## 5.1 Diagnostics

For an image with $K = 5$ references in the order each release defines (annotation id for COCO-style files, file line order for Flickr30k, list order for UIT-OpenViIC), call an object class a *doubleton* if exactly two references name it.<!-- code: .session_backup/2026-10-14/r11_litmaps/L2/scripts/adjacency_check.py coco_style(path, extract, order='id') sorts each image's captions by annotation id; flickr_entities() uses file line order; openviic_panel() keeps list order; called by .session_backup/2026-10-14/r11_verify/c1_b1_b6_reproduction.py run_b2 -->

Under (A1), the pair of references that name a doubleton is a uniformly random pair, so they are adjacent with probability
$$p_{\text{adj}}^{\,0} = \frac{K-1}{\binom{K}{2}} = \frac{4}{10} = 0.40 .$$
The **adjacent-doubleton share** is the observed fraction of doubletons named by adjacent references, pooled over images, with an image-bootstrap interval; it depends on the order chosen. A companion statistic, the **lag-1 Jaccard excess** (mean Jaccard similarity of the object sets of references at lag 1 minus the mean at lags 2–4; 0 under (A1)), and per-slot profiles separate the mechanisms that can raise it (Supplementary S5): a writer who types all references of an image in sequence raises both statistics, while independent writers raise neither.

## 5.3 What fails when references are not exchangeable

Positively dependent references cover fewer objects, so $k$ captions from one writer act like $k_{\text{eff}} < k$ independent ones and the crossing of Section 4 moves to larger $k$; if a writer names different kinds of objects in early and later captions, first-$k$ and random-$k$ designs give different slopes (Supplementary S1, S5). On COCO both effects are absent: an adjacent pair of references is worth $k_{\text{eff}} = 1.99$ [1.967, 2.020] independent references<!-- src: .session_backup/2026-10-26/a_full5000/out/h4_r4_full5000_all9.json (sha256 39c97d0de681) :: T3.k_eff_adjacent_pair_slots2to5.point/.ci; r4 = 9 systems x 5,000 (FILL_RULE, PI-1026c) -->, and the first-$k$ and random-$k$ one-reference slopes are −4.30 [−5.33, −3.27] and −4.77 [−6.10, −3.54]<!-- src: .session_backup/2026-10-26/a_full5000/out/r4_full5000_all9.json (sha256 332da8b6264c) :: gold.refs1_firstk.{slope,slope_ci}, gold.refs1_randk.{slope,slope_ci}; r0 wording "agree (−4.21 vs −4.28)" has no FILL_RULE branch, values printed as computed; r4 = 9 systems x 5,000 (FILL_RULE, PI-1026c) -->.
