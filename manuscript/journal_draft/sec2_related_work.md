**Object hallucination metrics.** CHAIR (Rohrbach et al., 2018) scores the share of mentioned COCO classes absent from a gold built from instance labels and reference captions. It is precision-type, so naming fewer objects can lower it. POPE (Li et al., 2023) replaces free-form scoring with yes/no probing; CCEval (Zhai et al., 2023) balances mean caption length and object count across models, on means only; AMBER (Wang et al., 2023) reports a coverage score next to its hallucination rate; THRONE (Kaul et al., 2024) uses class-wise precision, recall and an F0.5-score; and ALOHa (Petryk et al., 2024), OpenCHAIR (Ben-Kish et al., 2024) and CAOS (Datta and Sundararaman, 2025) extend the vocabulary beyond COCO-80. **Length and count as confounds.** LeHaCE (Wei et al., 2024), the closest prior work in method, fits a model-specific curve of hallucination against description length and evaluates every model at a uniform length. Our controls instead match the number of mentioned objects per image exactly, with paired intervals, and are applied to other groups' released outputs. SumGD (Min et al., 2025) reports recall next to CHAIR because shorter captions lower it; "Less is More" (Yue et al., 2024) shortens outputs and accepts the recall loss; OPERA (Huang et al., 2024) fixes token budgets, not object counts. **Position of this paper.** Three features separate this paper from that work. First, the gold is the experimental factor: each caption is matched once and scored against nested reference golds and instance or verified labels (Section 3.1), whereas the gold-quality studies above change classification or probing labels; captioning differs because the captioner chooses how many objects it names. Second, the count control matches the number of mentioned objects on every image of released captions, where LeHaCE fits length curves and CCEval balances means. Third, every prediction is registered or labelled exploratory or post hoc, failures included (Table 1). Prior work knows that incomplete gold inflates hallucination scores (Rohrbach et al., 2018) and that writers name objects selectively (Misra et al., 2016); what this paper adds is gold completeness as a controlled factor that can set the sign of F1's verbosity slope, and a size-matched deletion null that quantifies that reporting bias on a 50-reference gold.
