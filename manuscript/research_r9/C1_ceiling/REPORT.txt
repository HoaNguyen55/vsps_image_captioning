Bottom line.
- KTVIC: P, R and F1 >= 90 at once is ABOVE THE NOISE CEILING OF THE METRIC ITSELF. A predictor that knew the exact
  probability with which a KTVIC annotator names each object (no image-only system can know more) scores at best F1
  86.5-89.4 against one 5-reference union, and its balanced point is P = R = 86-88. The only 90/90 point is the
  oracle that reads the test references (top-4 gold classes: P 100 / R 90.4), whose text is an object list
  (CIDEr 30.7 vs 143.9 for fuse2-short). Realistic headroom: from F1 64.8 to the 2-4-human band, 72-82.
- COCO: F1 >= 90 is above everything measured (best 75.4) and at the edge of class-level recognition SOTA. The best
  F1-reporting multi-label classifier (Q2L, OF1 86.8) maps to 87.7-87.9 here even if its labels were written into
  the caption verbatim (the matcher is lossless). Five English annotators together reach 79.5.

3. KTVIC: annotator-noise ceiling (noise_ceiling.py)
----------------------------------------------------------------------------------------------------------
Model: per image, each nameable class has a naming propensity p; each of the 5 annotators names it independently with
probability p; p ~ Beta(a, b) fitted by ML to the zero-truncated support counts. Beta: a 0.448, b 1.315 (chi2 24 on 3
df). 2-component Beta mixture: w .50, (3.73, 8.53) and (0.30, 0.62), saturated on the 5 support cells (chi2 0 is not
evidence by itself). Parametric bootstrap: observed classes get p from their posterior, unseen classes are added
(46% / 33% of nameable classes are unseen by 5 annotators), and a FRESH annotator panel is drawn (40 replicates).
VALIDATION (the reason to trust it): both models reproduce all 10 measured human k-vs-j cells (P, R, F1) within
1.6 (Beta) / 1.0 (mixture) points, e.g. 1v4 84.8/46.2 and 85.4/46.3 vs 85.3/46.9 measured, 4v1 42.5/85.7 and
43.0/86.2 vs 42.9/85.9.
Ceiling: the oracle that knows every p exactly names {c : P(c in the 5-union) >= tau}. Against a fresh 5-union:
   tau     Beta P / R / F1 / |M|           mixture P / R / F1 / |M|
   .40     81.6 / 91.6 / 86.3 / 4.10       82.7 / 96.8 / 89.2 / 4.33
   .45     83.5 / 89.7 / 86.5 / 3.91       83.7 / 95.9 / 89.4 / 4.23
   .50     85.2 / 87.6 / 86.4 / 3.73       84.7 / 94.6 / 89.4 / 4.11
   .55     86.9 / 85.2 / 86.0 / 3.54       85.8 / 92.9 / 89.2 / 3.97
   .60     88.6 / 82.6 / 85.5 / 3.34       87.0 / 90.7 / 88.8 / 3.81
   .65     90.1 / 79.8 / 84.6 / 3.16       88.4 / 87.7 / 88.0 / 3.61
   .70     91.6 / 76.5 / 83.4 / 2.96       89.8 / 83.8 / 86.7 / 3.37
   .80     94.7 / 68.4 / 79.4 / 2.51       93.0 / 72.1 / 81.3 / 2.75
Sensitivity to the unseen-class count (Beta): x0.5 -> max F1 89.0 (but the model then overshoots the human matrix,
1v4 87.0/48.6); x2 -> 83.0; x3 -> 80.1 (both contradict the measured human matrix: 1v4 P 81.0 and 78.2).
Mixture with x0.5 / x0.25 unseen classes: max F1 90.5 / 91.4, max min(P,R) 88.8 / 89.9, but these overshoot the
measured humans (1v4 P 86.3 / 87.6 vs 85.3; 2v3 P 77.4 / 79.1 vs 76.1), i.e. the data reject them.
Reading: no tau gives P >= 90 and R >= 90 in any variant (best 89.9, in a rejected one); F1 >= 90 is not reached by
either validated model and needs assumptions the human matrix rejects. The ceiling is an upper
bound for any image-only system: real systems must ESTIMATE p from pixels. Assumptions that could move it: annotator
independence (annotators share a ~1.7-class budget per caption; the human-matrix fit says the effect on P/R is small)
and exchangeability (one Beta for all classes and images). The oracle uses one global tau; a per-image
expected-F1 set choice could add a little (not computed; P is pooled over images, so the rule is not separable).

6. What this means for R9 proposals
----------------------------------------------------------------------------------------------------------
- Ask "fraction of the ceiling", not ">= 90": on KTVIC F1 the defensible bands are 1 human 59-60, 2 humans 72-73,
  4 humans 79.5-82.4, noise ceiling 86.5-89.4 (vs a fresh 5-union). Current 64.8 is above 1 human, below 2.
- The KTVIC lever with the most measured headroom is RECALL at high |M| WITH calibrated selection: the Bayes rule above
  names classes whose probability of being in the 5-union is >= ~0.5, i.e. ~3.7 classes at P ~85. Existing systems
  at |M| ~4 give P ~58 (vote ensemble) to ~66 (fuse2-detailed bin). That is the UPE-MBR direction of R8 (union-
  propensity expected F1); its ceiling, if propensities were perfect, is the table in section 3.
- Detector/presence tags do not help KTVIC (-6.9 F1 when appended) but are what COCO instance gold rewards: on COCO the
  only route toward 90 is a COCO-trained multi-label recognizer (Q2L/ML-Decoder-class, released checkpoints) whose
  classes are written out (~88 predicted), paid for in CIDEr (inventory text: 26.9-30.7 on KTVIC vs 143.9).
- Kill rule for any proposal claiming >= 90 on KTVIC: it must beat the noise ceiling, so it is reading the
  references (leak) or gaming the matcher; check for both.
