## 9. Limitations

- **Two backbones, and the effect is carried by one.** The in-domain gain is carried mainly by Qwen2.5-VL and was not detected for InternVL3 at its frozen configuration. We cannot say whether this reflects the model, its frozen k, order and prompt tail, or the deletion step that its frozen τ applies (Table 12). The study was not designed to separate these, and the τ = −∞ row is a secondary motivated by stage B, not a result about InternVL3.
- **Out of domain the gain was not detected (XM3600).** The registered XM-a criterion gave FAIL. No per-backbone XM3600 rule was registered, so the per-backbone rows are reported without a claim. The memory holds no XM3600 captions, and XM3600's references follow a different style. The result therefore says nothing about retrieval from an in-domain memory on a second dataset.
- **The metric is reference-based.** CIDEr-D rewards matching the references' wording. The stripped column removes the trailing-period effect, and the PTB column agrees with it. Still, part of any `ret` − `rand` gain may be closer wording of image-specific content rather than better content. The study has no human judgments; by design, it uses existing data and labels only.
- **Object measures depend on the matcher and the gold.** On OpenViIC, gold objects come from the union of the references, so a correct object that no reference names counts as an error. On XM3600, the verified labels cover only the mapped classes.
- **The memory and test sets come from related sources.** KTVIC and OpenViIC share images. We removed byte-identical and near-duplicate images between the memory and every protected set, and excluded the near-duplicates of the tuning set from the primary set. Overlaps below the pixel rule's thresholds would not be caught.
- **One test look, one machine, one run.** Each test set was decoded once with greedy decoding. The CIs capture image sampling, not run-to-run variation; the decode-parity checks found no such variation on development data.
- **No priority claim.** Retrieval in-context captioning has been studied before (Section 2). This paper's contribution is the controlled, preregistered comparison for Vietnamese, not the method.
