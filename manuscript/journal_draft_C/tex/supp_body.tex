\section{Supplement S. Registered per-run rows}\label{supplement-s.-registered-per-run-rows}

These rows are the registered aggregates the scorer wrote to each scored set's ledger:

\begin{itemize}
\tightlist
\item
  Qwen2.5-VL at its frozen τ = −∞;
\item
  InternVL3 at its frozen τ = 0.10 and at τ = −∞;
\item
  the zero-shot arms;
\item
  the CPU copy baselines.
\end{itemize}

They are copied from the ledgers with no recomputation. ``n/a'' marks a field that the scorer does
not define for that row. CIDEr-D columns are ×100 on that set's own document frequencies. Rates and
shares are fractions; ΔP\_cm is in precision points.

Rows that no rule registered (InternVL3 τ ∈ \{0.00, 0.20, 0.30, +∞\}, Qwen2.5-VL τ = +∞, verifier
AUROC) are left out of this table and are listed in Table S12 (Section 7.3). Table S13 gives every
registered and reported row of the English arm (Section 8). Table S14 gives every row of the
development-set mechanism ablations (Section 6.8), which are not test results.

\subsection{Instrument definitions}\label{instrument-definitions}

These definitions make the instruments of Sections 3 and 5 usable without the companion manuscripts.
All gold comes from existing released references or labels; no label was created for this study.

\begin{itemize}
\item
  \textbf{Scoring kit.} Candidates and references are lower-cased and segmented into words with
  RDRSegmenter (VnCoreNLP 1.2). CIDEr-D (×100) uses document frequencies over the scored set's own
  references. The \emph{stripped} column removes trailing punctuation tokens from candidates and
  references before scoring; the \emph{as-written} column keeps them; a PTB-tokenised column is also
  written. The kit is loaded by sha256, and its code is released with the study code.
\item
  \textbf{Vietnamese object matcher.} A lexicon matcher that maps Vietnamese words to object classes
  after tone-mark normalisation: the two placements of the tone mark in a syllable (for example
  \emph{hoà} and \emph{hòa}) map to one form. Each caption is matched once, and its classes are the
  distinct classes in order of first mention. The lexicon is the companion object-precision study's
  and is released with its kit.
\item
  \textbf{Count-matched precision P\_cm.} For image i, with M\_i(run) and M\_i(zs) the distinct
  matched classes of the run's caption and of the same model's zero-shot caption, k\_i =
  min(\textbar M\_i(run)\textbar, \textbar M\_i(zs)\textbar). tp\_cm counts how many of the first
  k\_i classes of the run's caption are supported by the gold, and tp\_cm,zs does the same for the
  zero-shot caption. ΔP\_cm = 100 · (Σ tp\_cm − Σ tp\_cm,zs) / Σ k\_cm. On every Vietnamese set the
  gold for an image is the union of the classes matched in its released references. Verified
  precision on XM3600 (XM-b) instead uses the released Open Images V7 human-verified labels, mapped
  to classes by the companion study's mapping rule, and counts all mentions rather than a matched
  number.
\item
  \textbf{English matcher.} The English port of the deletion step matches COCO-80 classes with the
  CHAIR synonym list \citep{Rohrbach2018CHAIR}.
\item
  \textbf{Verifier question.} For a neighbour-only class, the verifier is asked ``Is there \{np\} in
  the image? Answer yes or no.'', where \{np\} comes from the fixed 112-class English class map of
  the companion scoring study's verifier protocol; the score is defined in Section 3.4.
\item
  \textbf{Pinned revisions (moved from Section 3.3).} Every snapshot file is pinned by hash. The
  pinned revisions are unchanged from stage A:
\end{itemize}

\subsubsection{Power, precision and Monte Carlo error (Section
5.4)}\label{power-precision-and-monte-carlo-error-section-5.4}

\textbf{Power and precision (the power note is registered; the other rows are descriptive and post
hoc).} The stage-2 registration stated the power of the stage-B gate G1 (point ≥ +4.0, lower bound
\textgreater{} 0): at a standard error of about 1.85 per backbone, the chance of passing G1 was
about 50\% if the true pooled difference were +4. No separate power statement was registered for P1.
The achieved 95\% CI half-widths of the registered pooled estimands, from the decision files, were
1.02 (P1), 1.21 (XM-a), 0.97 (P1-EN) and 0.78 (S-NC). For scale, the SESOI is about 6.2\% of the
pooled \texttt{rand} score on OV-test, 3.7\% on XM-test2500 and 2.3\% on both COCO and NoCaps; the
observed pooled difference is about 13.9\% of \texttt{rand} for P1, 1.3\% for XM-a, 3.5\% for P1-EN
and 2.0\% for S-NC. On COCO, where scores are higher, the same +2.0 is therefore relatively more
lenient. XM-a's upper bound (1.97) lies just below +2.0.

\textbf{Monte Carlo error of the bootstrap (post hoc, approximate).} Percentile endpoints at B =
2,000 carry Monte Carlo error. Under a normal approximation to each bootstrap distribution, the
standard error of a 2.5\% or 97.5\% endpoint is about 0.06 bootstrap standard errors, which is at
most about 0.05 CIDEr-D or precision points for every registered row. The registered bound closest
to its threshold is XM-a's lower bound (−0.45 against 0), about twelve such standard errors away, so
no verdict depends on this error.

\textbf{Images read by an unrelated pre-check.} A pre-check for another project read reference

UIT-ViIC training ids, using ids only. The lists overlap: the parts are 133, 59, 14 and 21, which
sum to 227 because an image can sit in more than one list. The 924 UIT-ViIC validation images whose
references the pre-check also read include 0 refused ids.

\begin{itemize}
\tightlist
\item
  what was read were UIT-ViIC Vietnamese references and their COCO-English counterparts;
\item
  no OpenViIC, KTVIC or XM3600 reference was read, so no reference that this paper scores against
  was exposed, whatever pixel overlap may exist between the source image pools.
\end{itemize}
