# Retrieved or Random Examples? Preregistered In-Context Captioning in Vietnamese and English

## Abstract

Retrieval in-context captioning shows a multimodal model the captions of training images similar to the query. It needs no training, which suits a low-resource language such as Vietnamese, but a gain over zero-shot prompting may reflect in-domain caption style rather than retrieval. A preregistered study with one look per test set compares retrieved examples with the same number of random captions from the same memory, for Qwen2.5-VL-7B and InternVL3-8B, in Vietnamese and, as a frozen-configuration transfer arm, in English. On OpenViIC test (1,941 images) retrieved examples beat random ones by +4.49 [3.52, 5.57] stripped CIDEr-D points pooled (registered PASS), carried mainly by Qwen2.5-VL and not detected for InternVL3, whose registered arm includes a verifier-based deletion step; object precision against zero-shot stayed above the registered floor. On COCO Karpathy test the pooled gain was +3.08 [2.08, 4.03] PTB CIDEr-D (PASS), again carried by Qwen2.5-VL; InternVL3's reported row was below zero (−1.64 [−2.79, −0.49]). Outside the memory's source neither registered prediction passed: XM3600 Vietnamese +0.70 [−0.45, 1.97]; NoCaps +1.73 [0.94, 2.50], with the CI above zero but the point below the +2.0 threshold. Crediting a gain to retrieval needs an equal-k random control and per-backbone results.
