5. LITERATURE (2022-2026 focus; arXiv API 20 queries in lit/arxiv_01-20.txt, 8 web searches, IDs verified via arXiv API in
   lit/verify_ids.txt; full text or HTML read for SelfVal and IC3. OpenAlex / Semantic Scholar not used.)
======================================================================================================================
Queries: self-consistency x caption; MBR x caption; hallucination x caption x consensus; captioning x object hallucination x
sampling; caption x hypernym/hedging/specificity; committee consensus; atomic/universal self-consistency; MBR x hallucination/
factuality; caption completeness/recall x sampling; test-time augmentation x LVLM hallucination; constrained beam search x tags;
MBR x F1; pseudo-references x multi-system MBR; Vietnamese captioning x decoding; caption x TTA; base model x fine-tuned rerank;
web: sample-vote hallucination, hedging back-off, object-utility MBR, view consistency, caption fusion recall, independent
second reference set, multi-crop verification, base-model evidence.
Closest prior and what it already does:
- IC3, Chan et al., EMNLP 2023 (2302.01328): K = 10 samples (T 0.95-1.15) summarized by GPT-3. Recall up, but COCO CIDEr
  132 -> 50 (OFA) and 132 -> 33 (BLIP); no hallucination metric. Recall bought at full typicality cost.
- Atomic Self-Consistency, Thirukovalluru et al. (2405.13131, 2024): merges authentic subparts of samples to raise recall
  (long-form QA). Text analog of completion. Universal Self-Consistency (2311.17311) selects the most consistent sample.
- SelfVal, Liu et al. (2601.22451, 2026): validates objects across sampled captions with extra LVLM probability queries
  (AUROC 0.85), then Best-of-N or Filter-then-Aggregate by the same LVLM. Precision-oriented; reported recall falls with
  stricter filtering; no reference-typicality measure.
- TLC-L, Petryk et al. (2305.07021): token confidence for caption correctness. SelfCheckGPT, EMNLP 2023 (2303.08896):
  sample consistency as a hallucination detector (text).
- CBS, Anderson et al., EMNLP 2017 (1612.00576): tag-constrained beam search (detector tags), the generative completion analog.
- MBR with content/factuality utilities: ConSUM, ACL 2026 Findings (2605.29336, summarization: consensus MBR + source
  consistency); HUMBR (2604.11141, hybrid utility MBR against hallucination); MBR-CBDT, EMNLP 2025 (2509.12677, retrieved
  same-panel refs, has captioning); Farinhas et al. 2023 (2310.11430, multi-system hypothesis ensembling).
- Augmentation: VCD (2311.16922) contrasts distorted images (opposite use). No view-consistency mention vote found.
- F1 decision theory: Lipton et al. (1402.1892): the F1-optimal threshold is F*/2.
- Not found: a decode method that reports agreement with an independent second human panel to separate truth from typicality;
  base-model mentions used as style-free evidence for a fine-tuned captioner; any of this for Vietnamese (only VieCap4H 2209.01304).
Verdict: CC-ADD and its base-evidence variant are incremental: an application of sample/committee consensus to recall with a
typicality constraint. The measurement design (two panels + COCO instances) is the most novel part, and it is analysis.

6. PROPOSALS (at most 2). Any GPU use is a new judge decision.
======================================================================================================================
P1. CC-ADD: typicality-anchored consensus completion (+ optional support hedge)
  Mechanism: k samples -> class support on the CHAIR-vi lexicon with hypernym closure -> keep greedy unless the closest
    alternative keeps greedy's supported classes and adds only classes with support >= t (frozen t = 3/8, keep 1/8);
    optional hedge (person class with support < 1.5/8 -> "nguoi"). GPU version: near-greedy alternatives (T = 0.7 samples) to
    cut the KTVIC cost, and a self-tag re-decode (evaluate.py --tags with the supported omitted classes; no code change) to
    reach more of the +6.1 R ceiling.
  Novel element vs closest prior: recall from consensus WITHOUT leaving the reference-typical operating point (IC3 loses
    60-100 CIDEr; SelfVal targets precision with extra LVLM queries; ASC is text), plus the F1-decision argument for why
    recall, not precision, is the lever on an unseen panel. Incremental.
  Pilot: (a) -1.2 [-4.7,+1.7]; (b) panel F1 +1.1 [+0.5,+1.9], R +1.1 [+0.5,+1.7], panel CIDEr +0.61 ns; vs matched control
    F1 +0.82 [+0.17,+1.57]; vs K2-lex@1.0 F1 +1.1 ns, CHAIR_i worse on 1 of 2 splits; (c) cross-system analog COCO R +3.4
    [+2.9,+4.0], F1 +3.1 [+2.6,+3.6], KTVIC test -0.4 [-2.1,+1.2].
  GPU (about 4.5 GPU-h on one 3090, from R6 unit costs: 6 short samples ~3.6 s/image):
    J1 dev300: p1dev_s42 e5_sample.py --images-file data/splits/ktvic_dev300.txt --split train_data.json --prompt short --n 16
       --temperature 0.7 --top-p 0.95 --limit 0 (~0.8 GPU-h).
    J2 COCO: p1_s43, NCS_DATASET=coco_vi e5_sample.py --split test_data.json --limit 0 --prompt short --n 8 --temperature 0.7
       (2,441 clean Karpathy-test images, ~3.3 GPU-h); score with score_coco_probe matcher v2 vs instance labels.
    J3 (optional): self-tag re-decode on images with supported omitted classes (~0.4 GPU-h).
  Kill (pre-register before J1/J2 output): (1) J2: instance-only F1 or R CI includes 0, or CC-ADD minus the matched
    random-switch control F1 CI includes 0; (2) J1: panel F1 CI includes 0 or KTVIC cost > 3; (3) coordinator's bar: on J1,
    CC-ADD (+hedge) minus K2-lex@1.0 on panel F1 must have CI > 0 with the panel CHAIR_i upper CI < +1.0; otherwise it stays
    analysis.
P2. Base-model evidence: the pre-fine-tuning model as a style-free proxy for an unseen panel
  Mechanism: same decision rule as P1, but class support comes from the zero-shot base model's own captions (short +
    detailed). The adapter keeps the phrasing (typicality), and the base model supplies content that fine-tuning on terse
    KTVIC refs suppresses. This is the task's "pseudo-references that do not share KTVIC style", used at the mention level only.
  Novel element vs closest prior: multi-system MBR / committees (ECO, Farinhas 2023) and MBR-CBDT draw evidence from
    same-style systems or same-panel refs; contrastive or proxy decoding uses the base model's logits, not its mentions. Not
    found in the scoop searches. Modest at best.
  Pilot: (a) dev not measurable (no zero-shot dev outputs); KTVIC test estimate -0.9 [-3.6,+1.8]; (b) none yet;
    (c) COCO instance-only R +4.9 [+4.3,+5.5], F1 +4.2 [+3.6,+4.7] vs matched control +2.9 and vs KTVIC-style evidence
    F1 +0.95 [+0.68,+1.24].
  GPU: zero-shot greedy short + detailed on dev300 (~0.5 GPU-h; detailed outputs are long), plus J2 reused.
  Kill: (1) on dev, base-evidence CC-ADD minus self-sample CC-ADD on panel F1 CI includes 0; (2) the coordinator's bar
    (beat K2-lex@1.0 on panel F1, CI > 0) at KTVIC cost <= 3; (3) on J2-style single-model COCO pools, gain over the matched
    control CI includes 0.
Not proposed: content-only MBR (fails, sec. 3a); hidden-state probe critic (R6 P-B4-2: equal to the vote veto, TLC-L prior);
augmentation-consistency votes (design only: greedy decodes under 4 crops/flips as evidence, ~0.4 GPU-h on dev300; no prior
found, but the T=1.0 evidence already carries AUROC 0.755, and it targets the precision side, where F1 cannot move).
