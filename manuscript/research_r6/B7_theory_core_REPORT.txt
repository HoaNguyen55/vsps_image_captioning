2. THEORY (derived from the three verified findings; each statement has a test in section 3)
==========================================================================================================================
T1 Centroid identity (lemma, exact without CIDEr-D's clipping and length penalty, by linearity of the inner product):
   CIDEr(c,R) = (10/4) sum_{n=1..4} <g_n(c), gbar_n(R)>,  gbar_n(R) = (1/|R|) sum_j g_n(r_j), g_n = unit tf-idf vector.
   E_R[CIDEr] = alignment with the panel centroid mu_n(x). Consequences:
   - every CIDEr lever either estimates mu(x) better for the decision (model samples, committees = model-based
     estimates; retrieved train refs = neighbourhood estimate) or decides better given it (MBR, RL);
   - an RL reward on a train image needs mu(x_i); the own 5 refs give an unbiased but noisy estimate. Empirical-Bayes
     (James-Stein) shrinkage m = (1-lam) gbar(T) + lam gbar(N) has least-squares weight
     lam* = sum <gbar(T)-gbar(E), gbar(T)-gbar(N)> / sum ||gbar(T)-gbar(N)||^2  (held-out refs E independent of T|x).
T2 CHAIR as mention-worthiness: a proposed noun o is flagged iff no ref names o (or a hyponym). With proposals mostly
   present, P(flag) ~ 1 - s_A(o|x), s_A = P(panel A names o | o present, x). CHAIR_i vs refs is a typicality metric.
T3 Identifiability: with one panel only pi_A = P(present) s_A is observable; a second panel B on the same images makes
   "present" observable (named by A or B; 84% joint recall, R5-01) and so identifies s_A (capture-recapture logic).
   Prediction tested in S1/S4/C: identified salience improves the KTVIC critic and two-panel labels improve a learner.
   RESULT: REFUTED for metric purposes (bottom line b). Reason: given the context (CLIP neighbours), the KTVIC naming rate
   already carries the salience information; the other panel's mention policy is a different typicality.
T4 Frontier = salience-ranking quality of the learner. Target policies that use one panel only change the operating
   point (count); ranking improves only with new information about the SAME panel (neighbourhood evidence), variance
   reduction (committees), or a decision rule that uses object-level panel evidence (veto; CHAIR term in the reward).
T5 Typicality axis: the reward r = CIDEr(c, own refs) + lam CIDEr(c, neighbour refs) moves along one axis; same-panel
   metrics prefer lam > 0, an independent panel prefers lam <= 0. Pre-registered prediction "lam* is smaller where
   references are exchangeable" (UIT-ViIC, COCO): REFUTED -- lam* is ~0.87 there vs 0.75-0.84 on KTVIC (N2b), so the
   shrinkage is a generic small-sample property of n-gram centroids, not a paraphrase-chain effect.

P-B7-1  PB-RLOO: panel-Bayes reward for CIDEr RL (neighbour-shrunk reference centroid + reference-gold CHAIR term)
  Mechanism. Drop-in reward for B1's CN-RLOO (same QLoRA policy/ref adapters, k = 8 rollouts, RLOO, k3 KL, EOS-aware
   word-level CIDEr-D, copy-neutral mask kept -- N5 shows NCR does not remove the copy channel):
     r(c; x_i) = (1-lam) CIDEr-D(c; R_i) + lam CIDEr-D(c; R_N(i)) - beta * #{o in nouns(c) : o not in CHAIR-gold(R_i)}
   R_N(i) = the 5 refs of each of the 10 train images whose refs are TF-IDF-closest to R_i (image and near-duplicates
   excluded; precomputed on CPU once). lam: James-Stein estimate from train refs (N2: 0.80) is the principled value;
   declared primary lam = 0.5 (proxy gains at 0.5 vs 0.8 are within CI, panel cost smaller), dev chooses {0.5, 0.8}.
   beta in {0.25, 0.5} chosen on dev300 (B2's file) with the rule "largest beta whose dev CIDEr is >= the beta = 0 arm - 1".
   Reward cost on CPU: ~10x the plain reward (50 extra refs), still < 0.3 s per group.
  Novel element. The RL target is the panel-Bayes utility derived from T1-T2: (i) the per-image reference centroid is
   shrunk toward the same panel's neighbourhood with an empirical-Bayes weight estimated from held-out references
   (James-Stein on reference centroids, not on baselines); (ii) the hallucination term is the evaluation metric's own
   gold, and its value is shown to be partly off-frontier at matched object count; (iii) a sign test separates
   typicality (what the same-panel metric pays for) from distinctiveness (CIDErBtw) and reports the independent-panel
   cost, so the paper can state exactly what the gain is.
  Closest prior and delta. CIDErBtw (arXiv 2007.06877): same neighbour refs, opposite sign, no shrinkage estimate.
   Shrinkage baselines (arXiv 2511.03710): shrink the baseline, not the reward target. MOCHa (arXiv 2312.03631), CHAIR-DPO
   (arXiv 2508.20181), VES-RFT (CVPR 2026): object-fidelity terms (prior art for beta; delta: metric-matched gold and the
   matched-count test). Re3Cap (arXiv 2608.21305): retrieval only as prompt guidance. B1 CN-RLOO: plain CIDEr-D reward.
  Pilot. Done on CPU (N1-N5, section 3). GPU gate (~5 GPU-h, one RTX 3090 per arm): two G1 arms on 1,000 images of
   train minus dev300, matched KL to B1's CN-RLOO G1 arm and the same P1_dev init: (A) PB-RLOO lam 0.5 beta 0.25;
   (B) NCR-only lam 0.5 beta 0. Score dev greedy every 250 images (word-level CIDEr-D, CHAIR_i, distinct captions,
   neighbour-n-gram copy rate).
  Pre-registered predictions (falsifiable).
   1. Dev, matched KL: A - CN-RLOO: CIDEr >= +1.5 and CHAIR_i <= -2.0 (paired 95% CIs excluding 0).
   2. Dev: B - CN-RLOO: CIDEr >= +1.0, |dCHAIR_i| <= 1.
   3. Independent panel (OpenViIC refs of the 555 test images, final models): B - CN-RLOO CIDEr <= 0 (typicality does
      not transfer); A - CN-RLOO CHAIR_i vs the OpenViIC gold <= -1.0.
   4. Control (lam = -0.25, CIDErBtw sign; optional 2.5 GPU-h): dev CIDEr below CN-RLOO by 0.5-1.5.
   5. Test, 3 seeds, pooled paired image bootstrap (5 seeds if a between-seed claim is made): PB-RLOO - CN-RLOO CIDEr
      >= +1.5 and CHAIR_i <= -2; vs P1 3-seed mean (145.8 / 18.4): CIDEr +6.5 to +12, CHAIR_i -4 to -7.
  Expected gain (KTVIC short, word level). vs CN-RLOO: CIDEr +1 to +3 (proxy +1.0 to +2.7 at 1 nat), CHAIR_i -2 to -3
   (proxy -3.1/-3.2 on 2-3 held-out refs, scaled by 18/27 to the 5-ref metric). vs P1 3-seed mean: CIDEr +6.5 to +12

   reaching B1's +5 to +9. UIT-ViIC: same reward with its own refs (lam* 0.87 by N2b); COCO-language-agnostic.
  GPU-h. Gate 5 (+ P1_dev adapter shared with B1). Full: 3 KTVIC seeds x ~10 = 30 (these replace CN-RLOO's seeds if the
   gate passes) + UIT-ViIC 3 x ~2 = 6 -> ~41 total, ~11 incremental over B1's plan. COCO 10K subset +15 if required.
  Kill criterion. At the G1 gate: kill PB-RLOO if A - CN-RLOO dev CIDEr < +1.0 AND dev CHAIR_i > -1.5; keep only the

8. CAVEATS
==========================================================================================================================
- The RL evidence is a one-step proxy on 6 samples of two SFT policies (test images). Full RL can drift outside the
  sample support; NCR at high lam could teach generic, neighbourhood-typical phrasing (watch distinct captions).
- CHAIR_E in N1 is measured against 2-3 held-out refs (baseline 27-31%), so its deltas overstate 5-ref CHAIR deltas;
  section 6 scales them by ~0.67.
- S2/S3 numbers come from one seed per adapter (P1 s43 is a low seed: 143.9 vs 149.8 for s42). Regression to the mean is
  possible; s42/s44 samples cost 1.1 GPU-h.
- The critic was fitted on test candidates of the other adapter (no dev candidates exist yet; P1 saw every train image).
- lam* from N2 is the MSE-optimal centroid shrinkage, not the reward-ranking optimum; N1 brackets it (0.5-0.8).
- The 2-panel variant (ctx2) used OpenViIC TRAIN captions as a feature, so the OpenViIC judge is not independent for it;
  the proposed critic (ctx) does not read OpenViIC.
- Paraphrase-chain dependence of the KTVIC refs (B2) affects held-out splits; contiguous blocks were used throughout.
