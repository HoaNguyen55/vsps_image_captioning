## 1. The rule (frozen)

UPE-MBR = Unseen-Panel Expected-object-F1 MBR. It is a decode-time rule over one adapter's pool of seven captions per
image: the greedy caption and 6 samples. It reads no reference of the image it captions.

    U(c)   = mean_{j != c} CIDEr-D(c, pool_j) + CIDEr-D(c, refs of the 10 train images whose 1-2-gram TF-IDF is
             closest to the greedy caption) + LAM * 10 * EF1(c)
    EF1(c) = 2 * sum_{o in M(c)} q_o / (|M(c)| + EG),  q_o = 1 - (1 - v_o)^M,
             v_o = share of the OTHER pool captions naming class o
    pick   = argmax U, but the greedy caption is kept unless max U - U(greedy) > MARGIN

| constant | value | meaning |
|---|---|---|
| LAM | 2.0 | weight of the expected-object-F1 term |
| M | 5 | describers in the unseen panel (union transform of the votes) |
| MARGIN | 0.5 | CIDEr-D/10 units a non-greedy caption must win by |
| EG | 6.0 | classes the unseen panel names per image |
| RETRIEVE | 10 | train images whose references enter the retrieval utility |
| K_SAMPLES | 6 | samples per image in the pool |
| LAM_LEX | 0.7 | weight of the LEX control (matched on dev to UPE's KTVIC cost, T3 p12) |

Pool:
- the greedy caption comes from `scripts/evaluate.py` (bf16);
- the samples come from `scripts/e5_sample.py`: short prompt, T*, top_p 0.95, top_k 0, seed 42, at most 160 new
  tokens.

Selection side:
- CIDEr-D is `rl_reward.CiderD` (word level: RDRSegmenter, then lowercase).
- Document frequencies and the retrieval index come from:
  - dev: KTVIC train minus dev300 (3,469 images);
  - test: all of KTVIC train (3,769 images);
  - UIT-ViIC: UIT-ViIC train (2,695 images).

Classes are those of each dataset's object metric:
- KTVIC: `rescap.chair.objects_in`, the 113-entry lexicon;
- UIT-ViIC: `score_coco_probe.vi_objects`, COCO-80, matcher v2.

Controls (same pool, same base utility, same margin):
- COUNT sets q_o = 1 for every class, so it uses no evidence. Its lam is chosen on the grid 0..3 (step 0.05) so that its
  mean classes per caption matches UPE's on that pool, ties going to the smaller lam. The choice reads no reference.
- LEX is the coordinator's lexicon baseline (K2 section 3) moved to decode time. Its term is K2's lexicon object F1
  against the other pool captions, with lam = LAM_LEX.

Provenance:
- T3 chose the constants on dev300 with the T = 1.0 G0 pool of P1_dev (8 rollouts plus greedy): p7 cross-fit, p8
  frozen, p12 for LAM_LEX.
- T3's test numbers come from legacy pools (p1_s43, fuse2_s42, 6 T = 0.8 samples each). They remain estimates and are
  not reused as confirmation (D9).

## 4. T* rule (frozen before step A's outputs exist)

- For T in {0.5, 0.8}, compare UPE with P1_dev's greedy caption on the 300 dev images:
  - KTVIC CIDEr-D against the 5 dev references, with evaluate.py's DF over the 300 dev reference sets;
  - panel object F1 against the union of the dev panel captions' classes.
- T* is the T with the highest panel object F1 change among the T whose KTVIC CIDEr-D change is >= -3.0. Both are point
  estimates.
- Within 0.05 F1, the higher KTVIC change wins, then the lower T.
- If neither T is eligible, T* is the T with the higher KTVIC change.
- `upe_mbr.t_star` implements this, and `_check` asserts every branch.

D9 asks for the highest cross-fitted panel F1. Every constant of the rule is frozen, so T is the only choice made on
dev. For a fixed T, a cross-fitted estimate therefore equals the full-dev estimate, and the rule uses all 300 dev images.

## 5. Predictions (verbatim from T3's report, section 5)

```
  Falsifiable predictions (pre-register before any new decode):
    F1 KTVIC test, 3 P1-assist seeds; samples at T* in {0.5, 0.8} chosen on dev300 with the P1_dev adapter.
       - Pooled vs greedy: panel object F1 >= +2.5 with CI > 0, panel P >= -1.5, KTVIC CIDEr >= -3.
       - Vs the decode-time lexicon term at dev-matched cost: panel F1 >= +0.8 with CI > 0.
    F2 UIT-ViIC test + val (1,155 images), P1 UIT-ViIC adapter, 6 samples:
       - COCO-instance R >= +2.0 with CI > 0 and instance P >= -1.0 vs greedy;
       - vs the count-matched control: instance P >= +1.0 (the evidence effect on truth).
    F3 KTVIC-reference CHAIR_i does not fall (delta >= -0.5): the gain is invisible to panel-K metrics.
    Kill if any of these holds:
       - F1's panel-F1 CI contains 0;
       - the count-matched control equals UPE on panel P (CI contains 0) on 2 of 3 seeds;
       - F2's instance P falls by more than 1.
```

Operational reading. All effects are B - A on the same images. CIs are 95% percentile intervals:
- object metrics: `object_prf.paired`, B = 5000;
- CIDEr-D: `rl_reward.boot`, B = 2000.

"Pooled" means the per-image rows of the three seeds (3 x 555 panel images), or of the two UIT-ViIC splits (1,155
images), concatenated. Point estimates decide the ">=" clauses; CIs decide the "CI > 0" and "CI contains 0" clauses.

| clause | output key (`upe_mbr.py`) |
|---|---|
| F1, pooled panel F1, P; KTVIC CIDEr | ktvic: `pooled.panel_obj_vs_greedy.F1/P`, `pooled.cider_vs_greedy` -> `verdict.F1a` |
| F1, lexicon term at dev-matched cost | ktvic: `pooled.panel_obj_vs_lex.F1` (LEX = K2's term at LAM_LEX 0.7) -> `verdict.F1b` |
| F3 | ktvic: `pooled.chair_i_ktvic_delta` (CHAIR-vi against the 5 KTVIC refs, pooled ratio) -> `verdict.F3` |
| F2 | uitviic: `pooled.inst_vs_greedy.R/P`, `pooled.inst_vs_count.P` -> `verdict.F2` |
| kill 1 | ktvic: `verdict.kill_panel_F1_ci_contains_0` |
| kill 2 | ktvic: per seed `vs_count.panel_obj.P` CI contains 0 -> `verdict.kill_count_control_equal_on_2_of_3_seeds` |
| kill 3 | uitviic: `verdict.kill_instance_P_falls_more_than_1` (pooled instance P point < -1.0) |

Definitions:
- KTVIC CIDEr-D is per-image CIDEr-D x 100 with DF from the 558 test reference sets (evaluate.py's value).
- Panel object P/R/F1 uses object_prf's exact classes against the union of the OpenViIC test captions' classes.
- COCO-instance P/R uses the instance classes only (`instance_gold.json`, key `coco`), with no reference classes added.

Consequences:
- If a kill rule fires, UPE-MBR is reported as a negative truth-side result and is not claimed.
- If a prediction fails without a kill, its numbers are reported and the corresponding claim is withdrawn.

## 6. Temperature reading (D9 iii)

R0 is plain KTVIC CIDEr-D selection, the F4 protocol of R6's S0 `dev_mbr.py`:
- the pick is the argmax over the 7-caption dev pool (greedy included) of CIDEr-D against the image's 5 dev KTVIC
  references (evaluate.py's DF);
- it moves fully to the argmax, with no partial move.

Reading, pre-registered:
- If R0's dev panel CIDEr-D gain over greedy at T = 0.8 has a 95% CI above 0 (`temperature_reading` in the step-B
  output), R6's F4 finding ("KTVIC rewards buy only typicality") depends on temperature.
- Otherwise F4 stands at T = 0.8 as well.

For context, F4 at T = 1.0 is +0.07 [-3.66, +4.11] (9-caption pool). T2's d = 0.5 proxy is a different selection and is
not this reading. The reading feeds the RL rollout-temperature question; it decides nothing in F1 to F3.

## 7. Reporting

- UPE results are reported as a separate truth-side result next to the KTVIC table. They never go into the "best KTVIC
  metrics" row.
- Next to every UPE number, report:
  - KTVIC CIDEr-D;
  - KTVIC-reference CHAIR_i (T3 measured +0.75 on dev and +1.6 / +2.4 in the test estimates; F3 expects it not to fall);
  - panel CHAIR_i;
  - classes per caption;
  - the share of images switched away from greedy;
  - the LEX and COUNT contrasts.
- Every seed and both UIT-ViIC splits are reported, whatever the verdicts.
- No step writes OpenViIC text. Outputs hold numbers, counts and file hashes only.
