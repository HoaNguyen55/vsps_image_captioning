## 5. Procedure (frozen)

- Step 0, before any training or scoring: re-decode p1dev_s42 on dev300 on this job's machine (evaluate.py, short prompt, bf16, its defaults) under the name p1dev_s42_redecode. Every paired comparison uses this same-machine decode. Its agreement with the registered n2 decode (share of identical captions, CIDEr-D difference) is reported, never used to select anything.
- Pool: e5_sample.py --adapter runs/p1dev_s42 --split train_data.json --images-file <RL ids> --limit 0 --prompt short --n 6 --temperature T --top-p 0.95 --seed 42, for T = 0.5 and 0.8; per image the 6+6 samples are merged in that order.
- Train-image greedy: greedy short-prompt decode of P1_dev on the RL images (evaluate.py's prompt and decoding settings): the CM-RFT count and the copy-guard baseline.
- Pairs (arm A): the M3 builder rules (draft .session_backup/2026-10-14/research_r10/M3/cm_pairs.py, to be committed as scripts/cm_pairs.py): candidates are the pool samples (greedy excluded), deduplicated, minus those empty, with CJK, ending in a function word, or copying a reference (rl_reward.copy_stat m >= 0.9); a pair (w, l) of one image needs |M(w)| = |M(l)| = k >= 1, |syllables(w) - syllables(l)| <= 2 and TP(w) >= TP(l) + 1 against ktvic5 train gold; at most 4 pairs per image, largest dTP first, then seeded random (seed 42).
- CM-DPO: train_stage2.py --stage dpo --data <pairs> --adapter runs/p1dev_s42 --out runs/cmdpo_A_s42 --epochs 1 --beta 0.1 --lr 5e-6 --grad-accum 8 --anchor-sft 1.0 --seed 42; reference = the start adapter (ref_sft); the anchor adds 1.0 x the response-only CE on the image's first human caption; no NLL on the chosen caption; first a 20-pair dry run (gradient check, peak reserved <= 22 GB, pair-ordering accuracy logged).
- CM-RFT: targets: per RL image, among the usable pool samples (same filters as the pairs) whose class count equals that of P1_dev's greedy caption, the one with the most ktvic5 train-gold classes, kept only if its TP exceeds the greedy's; ties by CIDEr-D against references 1-4 (leaving out reference 0, the SFT target; rl_reward.CiderD, train-minus-dev300 document frequencies), then the lower pool index. Rows: for each kept image one row with the target and one with the image's first human caption (1:1). train_stage2.py --stage sft --data <rft> --adapter runs/p1dev_s42 --out runs/cmrft_s42 --epochs 1 --lr 1e-5 --loss-mask assistant --seed 42.
- A-KL: runs only if arm A's verdict is KILL and guard G2 or G3 failed (R14-2: 'runs ONLY after a guard kill on G2/G3'): the anchor is replaced by a token-wise forward KL to pi_SFT on the chosen response (alpha 0.4), lr 2.5e-6, same pairs and settings otherwise; its verdict replaces arm A's.
- Decodes: evaluate.py short greedy on dev300 for each arm; greedy on the first 250 RL images for each arm (copy guard).
- Checkpoint: the last checkpoint only (gate v2 lesson); no best-of-checkpoints; checkpoints every 200 steps exist for resuming only.

## 6. Analysis

- Classes: objects_in (matcher v2), exact classes; m = mean distinct classes per caption.
- d_res: residual(x) = F1_ktvic5(x) - prereg_ladder_check.at(frontier, m(x))[2], with object_prf.scores F1 (P = sum TP / sum M; R = mean per-image recall) and the frozen frontier anchors of the ladder prereg; d_res = residual(arm) - residual(P1_dev same-machine decode).
- panel_cm: panel-side count-matched F1: on the 296 panel images with k_arm(i) = k_P1dev(i) (same number of distinct classes), object_prf.scores F1 against the panel classes, arm minus P1_dev; the matched share is reported (few matched images widen the CI, which the gate penalises).
- 95% CIs: paired percentile bootstrap: dev images for d_res, the matched panel images for panel_cm; B = 2000, numpy default_rng(0).
- Frontier (ladder prereg anchors): M1 1.7826, TP1 1.3996, b 0.7468, c0 5.4859, c1 25.9815. P1_dev's registered dev residual is +0.17 (F1 54.572, m 1.763).
- Reported: dP, dR, dF1 with CIs; dm; dCHAIR_i; dev CIDEr-D and BLEU-4 with the paired CIDEr CI; syllables, fragments, CJK count; panel plain dF1 and dm; the ktvic5 matched-count dF1 (same estimator as panel_cm); copy rates; pairs built, images with pairs, RFT images kept; DPO pair-ordering accuracy; d_res(A) - d_res(R) with its paired CI.

## 8. Gate, kill rules and consequences

- PD-9 Q2 conditions: d_res 95% CI lower bound > 0 (dev refs) and panel_cm 95% CI lower bound > −0.5 (panel side). Both are inside every PASS below.
- Guards (all must hold):
  - G1: |dm| <= 0.2 (dm = mean classes per caption, arm minus P1_dev).
  - G2: dev CIDEr-D x100 >= 141.33.
  - G3: at most 1 of 300 dev captions contain CJK (scripts/cjk_rate.score_mapping).
  - G4: mean syllables (rl_reward.syllables) in [10.69, 13.06].
  - G5: at most 15 of 300 fragment captions (rl_report.fragments: END from train-minus-dev300 references).
  - G6: copy guard (PD-9 Q2; gate v2's G4): exact-copy rate of the arm's greedy captions on the first 250 RL images <= 2 x max(P1_dev's rate on the same images, 1/250); an exact copy has rl_reward.copy_stat edit distance 0 to one of the image's 5 references (content words).
- **Arm A (and A-KL):** PASS iff all guards hold, d_res >= +1.5, d_res_lo > 0 and panel_cm_lo > −0.5; GREY iff all guards hold, panel_cm_lo > −0.5, not PASS, and either +0.5 <= d_res < +1.5 or (d_res >= +1.5 and d_res_lo <= 0); KILL otherwise.
- **Arm R:** PASS iff all guards hold, d_res >= +1.0, d_res_lo > 0 and panel_cm_lo > −0.5; GREY iff all guards hold, panel_cm_lo > −0.5, not PASS and d_res >= +0.3; KILL otherwise.
- S3 passes when an arm PASSES; GREY carries no claim and enables nothing without a new judge decision.
- H5: the 'both P and R rise' reading holds iff dP > 0 and dR > 0 (point); it is withdrawn if dR < 0 with its 95% CI upper bound < 0 (R14-2 writes 'dR < 0 with LB > 0', read here as a recall loss whose CI excludes 0); it does not change the gate.
- Consequences: S4 needs S2 G0 PASS and an arm-A (or A-KL) PASS (R14 synthesis Stage 2); S7 not opened by this job; it may be proposed only after S3 or S4 passes, as a new judge request with a fresh prereg (PD-9 Q3); M3 stages 2-3: the C1/C2 controls, the COCO arm and any test look need their own preregs; KILL: reported as a pre-registered negative with CIs.
