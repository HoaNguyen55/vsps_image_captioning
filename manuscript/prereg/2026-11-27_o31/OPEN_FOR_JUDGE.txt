B. DEFAULT SETTINGS WITH MORE THAN ONE PUBLISHED VALUE, OR NOT READ IN THEIR PRIMARY SOURCE

B1 DEFAULT. VCD.
  - alpha 1, beta 0.1 and noise step 500 are verified in SENTINEL Table 12 and in the group's port scripts/baselines.py (1b7bf812), which FAIR used.
  - The VCD paper's own §4.1 and App. A values were not read verbatim in the primary source. The page as read also showed a POPE noise step printed as "999999", possibly a rendering error.
  - The VCD paper samples tokens; the port and this erratum use greedy selection over the contrastive distribution.
  Recommendation: greedy, for comparability with S0 and with FAIR's VCD row. State the deviation in the paper.

B2 DEFAULT. DeCo.
  - The candidate layers are 20 to 28 (paper §3.1 and §4.1, not read verbatim). The tested 7B models have 32 decoder layers (their public configurations, not re-checked here). Qwen2.5-VL-7B has 28 decoder layers (config.json), and DeCo reports no Qwen2.5-VL model.
  - Writer's mapping: the same relative depth, which gives layers 18 to 24 (first decoder layer = 1). The alternative is the literal range 20 to 27.
  - alpha is given as "a range of 0.1 to 0.6" in the paper and as 0.6 in the README. The writer chose 0.6.
  - top-p 0.9 and top-k 20 come from the README only.
  - The official code must be read before C09 is written, and any difference comes back here.

B3 DEFAULT. EFUF CLIP score.
  - Paper Eq. 1 takes the maximum over windows; the repository has average_top_k = 4 by default. The writer chose the maximum (the paper).
  - CLIP ViT-B/32, 48 px patches and window 4 come from the repository, not read verbatim.
  - The text prompt form for an object (bare name, or a template) and the score scale (100 x cosine) are to be read in insight/clip.py before C12 and C21 are written.
  - The batch size for M5 training is the repository default, not yet read.

B4 DEFAULT. SENTINEL detectors.
  The checkpoints and thresholds of GroundingDINO and YOLO-World were not readable (model/detector/*.py returned HTTP 503).
  - Rule as drafted: use the values in the released code at a pinned commit, recorded with file and line before any detector output.
  - If a value is absent there, the judge names the detector's own published default before any output.
  - Also open: whether the released code prompts GroundingDINO per class or with all class names joined.

B5 DEFAULT. EFUF published thresholds (32 / 23 / 27.5) were calibrated on English captions of COCO images.
  M5 applies them unchanged, with no tuning, to the English class names of Vietnamese mentions on KTVIC images. This is a stated deviation in what is scored, not a tuned value.

D. CHOICES THE WRITER MADE

D1 CHOICE. T-4 places OP_strict = S1 (fixed budget B = 9) at the strict end, as registered for A-1.
  The first step of the dial therefore also changes the budget. The alternative strict end is A-8 (FAIR verdicts with the scaled budget, E-B6), which would cost one more tier-2 decode (4.5 h).
  Recommendation: keep S1 as registered. The 2 x 2 of E-B6 reports the budget share.

D2 CHOICE. T-4 tests the R ordering only.
  F04 proposed testing R and h. h is reported with its predicted direction (not decreasing), but it is not tested, because "h rises" is not a claim of the paper and it would add a member to family T.

D3 CHOICE. The T-4 variance.
  It is a normal approximation with an image-bootstrap variance plus 2 x a pooled between-seed variance (S1 and S2, three seeds each, 4 df). The alternative is the image bootstrap only, which ignores training noise for single-seed points.
  Recommendation: as drafted, with the 4 df stated in the paper.

D4 CHOICE. OP_25 and OP_75 are chosen over all 30 grid points, whether or not they meet P_floor, mirroring the OP_mid rule of E7.
  The alternative restricts them to points that meet P_floor.
  Recommendation: as drafted (it spans the dial).

D5 CHOICE. The shorter-prompt S0 decode uses PROMPTS["two"] (two sentences; the repository's length-matched control). Alternatives:
  - "short" (one sentence; far shorter than S2);
  - "instructed" (a precision-instruction prompt, which answers a different question, "is a clever prompt enough?").
  No new prompt string is written.

D6 CHOICE. The upper bound 12 for j in S0-trunc, and the sentence rule (end punctuation, line breaks, a final fragment counts).

D7 CHOICE. Family T has four members: T-1, T-2, T-3 and T-4.
