## 1. Scientific Question & Motivation

Count-matched pool ranking (`PLAN-F1` / `POOL-VOTE`) breaks ties among pooled candidate objects sharing the same empirical sample vote fraction $v(c)$ and greedy membership indicator $g(c) \in \{0, 1\}$ using only the global corpus mention prior $p_0(c)$ (`lp = logit(p_0(c))`). Because $p_0(c)$ is image-invariant, conditioning on $(v(c), g(c))$ leaves `lp` with negligible within-cell discrimination on `dev300` (mean sample-size-weighted within-`(v,g)`-cell AUROC $= 0.4517$).

Proposal P1 replaces the image-invariant corpus prior `lp` with an image-conditioned **text-kNN retrieval prior** `knn10(i, c)` computed from the $k = 10$ nearest training images in TF-IDF syllable-1,2-gram space of the candidate caption pool. On `dev300` (`n = 300` images, `1,306` pooled candidate items), `knn10(i, c)` achieves:
- Marginal item AUROC $= 0.7521$ (`[0.7259, 0.7779]`)
- Within-`(v,g)`-cell AUROC $= 0.6142$ (and `0.6108` under skip-top-1 scene-clone ablation)
- Out-of-fold count-matched `F1` at `PLAN-F1 k_i`: `60.13` (`+1.16 [+0.02, +2.29]` vs `(v,g)` tie-avg `58.97`; `+0.88 [-0.28, +2.05]` vs votes-only learned `59.25`; `+0.76 [-0.44, +1.95]` vs `POOL-VOTE` `59.37`)
- Independent panel transfer on the `296` OpenViIC-matched `dev300` images: $\Delta\rho_A = +1.09\text{ pp }[-0.05, +2.24]$, $\Delta\rho_I = +0.81\text{ pp }[-0.20, +1.83]$, panel gate $L = \Delta\rho_I - 0.35\,\Delta\rho_A = +0.44\text{ pp }[-0.50, +1.35]$.

Because `dev300` was used to select `k = 10` and inspect the `13`-caption vs `7`-caption (`T=0.5`) pool regimes, `dev300` is treated strictly as exploratory/fitting data. This document freezes the feature pipeline, logistic regression coefficients, count budgets, and primary/secondary decision gates prior to running `--test-eval` on the `n = 558` KTVIC test images across seeds `s42, s43, s44`.

## 2. Frozen Feature Pipeline & Model Coefficients

### 2.1 Text-kNN Retrieval Index & Query (`k = 10`)
1. **Index corpus**: All `3,727` KTVIC training images (`data/ktvic_dataset/train_data.json`), where each image document is the space-joined lowercase reference captions (`" ".join(refs).lower()`). Zero KTVIC test images appear in `train_data.json`.
2. **Vectorizer**: `TfidfVectorizer(ngram_range=(1, 2), min_df=2, sublinear_tf=True, token_pattern=r"(?u)\b\w+\b")` fitted on the training image documents.
3. **Query**: Space-joined lowercase pool captions (`[greedy] + samples`) for test image $i$.
4. **Neighbours**: Top $k = 10$ training images by cosine similarity (L2-normalised TF-IDF dot product; self-exclusion enforced if query ID ever appears in index).
5. **Laplace-smoothed logit prior**: Let $c_{\text{nn}}(i, c) \in \{0, \dots, 10\}$ be the number of retrieved training neighbours whose gold canonical object set contains $c$. Then:
   $$p_{\text{knn}}(i, c) = \frac{c_{\text{nn}}(i, c) + 0.5}{10 + 1}, \qquad \text{knn}(i, c) = \log\!\left(\frac{p_{\text{knn}}(i, c)}{1 - p_{\text{knn}}(i, c)}\right).$$

## 3. Pre-registered Test Evaluation Protocol & Decision Rules

### 3.1 Test Pools & Count Budgets
- **Test split**: `n = 558` KTVIC test images across seeds `s42`, `s43`, `s44` (`555` matched in `data/ktvic_openviic_refs.json` for panel transfer).
- **Pool composition per seed**: `1` greedy caption (`data/results/p1assist_s4{2,3,4}-short.preds.json`) + `6` sampled captions at $T = 0.5$ (`data/results/upe/test/p1assist_s4{2,3,4}-test-short-T0.5.jsonl`), giving `7` captions per image ($v = s_6 / 6$).
- **Primary count budget $k_i$**: Identical per-image count $k_i = \text{planf1\_k}(i)$ produced by `plan_f1.py`'s `dev300`-fitted calibrator (`w_plan_13`, `lam_13`, falling back to `greedy_k(i)` when empty), applied identically to all compared rankers (`KNN-PRIOR`, `(v,g)` tie-avg, `POOL-VOTE`, and `VOTES-ONLY-LEARNED`) so that $\Delta\text{F1}$ is strictly count-matched (`m` identical across rankers).
- **Secondary count-budget diagnostics**: `greedy_k` ($k_i = |G_i|$), `top3_k` ($k_i = \min(3, |U_i|)$), and `planf1_k_t05` ($k_i$ from the `dev300` $T=0.5$ 7-caption calibrator).

### 3.2 Primary Endpoints & Statistical Inference
1. **Primary Endpoint 1 (`dF1` vs `(v,g)` tie-avg at `planf1_k`)**:
   - Paired difference in pooled 3-seed count-matched micro object `F1` between `KNN-PRIOR` (`w_knn_13`) and analytical `(v,g)` tie-averaging expectation on KTVIC test (`n = 558` images $\times$ `3` seeds).
2. **Primary Endpoint 2 (`dF1` vs `POOL-VOTE` at `planf1_k`)**:
   - Paired difference in pooled 3-seed count-matched micro object `F1` between `KNN-PRIOR` (`w_knn_13`) and `POOL-VOTE` (`w_plan_13`, which breaks `(v,g)` ties by global prior `lp`).
3. **Resampling & Multiplicity**:
   - Image-clustered bootstrap with $B = 5000$ replicates (`seed = 0`), resampling the `558` test image IDs with replacement and averaging each metric across the `3` seeds (`s42, s43, s44`) per replicate.
   - Two-sided bootstrap p-values across `{P, R, F1}` adjusted by Holm-Bonferroni step-down.
   - Smallest effect size of interest (`SESOI`): $+0.50\text{ F1}$ points.
4. **Independent Panel Gate (`B5` rule on `n = 555` OpenViIC-matched test images)**:
   - Let $\Delta\rho_A$ be the paired change in per-image object recall on KTVIC gold (`555` matched images) and $\Delta\rho_I$ be the paired change in per-image object recall on the independent OpenViIC panel (`data/ktvic_openviic_refs.json`, aggregate recall only, zero raw strings logged).
   - Panel statistic: $L = \Delta\rho_I - 0.35\,\Delta\rho_A$.
   - **Panel gate (`panel_gate_pass`)**: `CI_95(d_rho_A)[0] > 0` AND `CI_95(L)[0] > 0`.
5. **Overall Decision Outcomes**:
   - **`HEADLINE_PASS`**: `dF1 >= +0.50`, `CI_95(dF1)[0] > 0` (`p_holm < 0.05`) against **both** `(v,g)` tie-avg and `POOL-VOTE`, AND `panel_gate_pass == True`.
   - **`SECONDARY_POSITIVE_OR_INCONCLUSIVE`**: `dF1 > 0` against `(v,g)` tie-avg or `POOL-VOTE`, or `within-(v,g)-cell AUROC > 0.55`, without clearing the full `HEADLINE_PASS` + `panel_gate_pass` bar; reported as a pre-registered count-matched tie-breaking diagnostic explaining why `7`-caption $T=0.5$ test pools have wider `(v,g)` tie cells than `13`-caption multi-temperature `dev300` pools.
   - **`NULL`**: `dF1 <= 0` on primary endpoints; reported transparently in the negative-result ledger alongside the `dev300` vs test pool-size comparison.
