0. BOTTOM LINE
- The idea as posed (synonyms, hypernyms, learned name merges) closes only ~30% of the gap between within-KTVIC
  and cross-panel human F1. That holds on dev300 (gap 17.9 -> 12.1) and on the frozen test look (15.7 -> 10.8).
  Chance-corrected cross-panel agreement kappa rises only 0.65 -> 0.71.
- About 70% of the gap is SELECTION policy (which objects get mentioned), not naming. Restricting to things closes it:
    * COCO-80 projection: gap -2.4 (dev300) / -4.2 (test), kappa 0.89 / 0.96;
    * a Vietnamese-preserving THING tier of the 113-class lexicon: gap 6.4, kappa 0.73 (dev300);
    * the scene tier keeps a gap of 22.7.
- System side (73 outputs, test, exploratory, not count-matched):
    * the KTVIC-gold vs OpenViIC-gold ranking tau goes from 0.55 (exact) to 0.67 (COCO-80);
    * the "home advantage" of KTVIC-fine-tuned systems over zero-shot falls 9.8 -> 2.8 F1;
    * naming layers leave both unchanged (tau 0.51-0.55, home 9.7-10.1).
- Proposal: a two-tier object metric (guideline-invariant THING tier + guideline-specific SCENE tier) plus an
  invariance audit: cross-panel kappa against a shuffled-image null, and a naming/selection decomposition.
  Value: it explains the 60.5 vs 45.0 human-ceiling discrepancy and defends the object metric. Novelty: moderate.
  Soft and hierarchical matching are known; the two-panel, same-image audit was not found in prior work.

1. PROBLEM AND HYPOTHESES
Object F1 against reference captions depends on the guideline. Same images, matched (data/ktvic_openviic_refs.json):
- a KTVIC annotator vs the other 4 KTVIC refs scores F1 60.5;
- an OpenViIC annotator vs the 5 KTVIC refs scores 45.0.
So a human ceiling, or any cross-dataset comparison, says as much about the guideline as about the captioner.
Decomposition into: count (OpenViIC names 2.27 classes/caption vs 1.74), gold size (4 vs 5 refs), NAMING (synonyms,
dialect, hypernym level), and SELECTION (what is worth mentioning).
  H1 (naming share): synonym + hierarchy + data-learned merges close <= 35% of the F1 gap.        [supported, §3]
  H2 (selection share): restricting to a thing vocabulary closes >= 60%.                          [supported on dev300]
  H3 (systems): under the thing tier, cross-gold system ranking tau rises >= 0.10 and the FT-vs-ZS home advantage
      shrinks >= 50%, also at MATCHED COUNT.                    [supported un-matched (exploratory); matched = Gemini]
  H4 (calibration): classes with low within-KTVIC annotator consistency pi_c are the ones that diverge across
      guidelines, so pi_c-weighting yields invariance.                                             [FALSIFIED, §3]
  H5 (validity): any soft matcher that "closes the gap" must not inflate the shuffled-image null; otherwise the
      closure is spurious.                                       [supported: learned free merges fail exactly this way]

2. CLOSEST PRIOR WORK (V = verified by web search today; U = not re-verified this session)
- [V] ALOHa: Petryk et al., NAACL 2024 short, arXiv:2404.02904. LLM object extraction, semantic similarity, Hungarian
  matching; an open-vocabulary CHAIR. Soft matching is NOT new. New here: invariance across annotation guidelines,
  tested on two human panels of the same images, with a chance-corrected null. Novelty vs this: moderate.
- [V] CAPTURE: Dong et al., arXiv:2405.19092. Extracts objects/attributes/relations, matches "through three stages".
  [U: that the stages are exact / synonym / soft-embedding.] Same delta as ALOHa. Moderate.
- [V] OpenCHAIR / MOCHa: Ben-Kish et al., arXiv:2312.03631. Open-vocabulary hallucination benchmark. It does not address
  reference-guideline dependence. Moderate.
- [V] Hierarchical P/R/F: Kiritchenko, Matwin, Nock & Famili 2006 (Canadian AI, pp. 395-406);
  Kosmopoulos et al., DMKD 29:820-865 (2015), arXiv:1306.6802, doi:10.1007/s10618-014-0382-x.
  Our L2 is exactly ancestor-augmented hP/hR. Novelty of L2 itself: LOW.
- [V] ManyNames: Silberer, Zarriess & Boleda, LREC 2020 (aclanthology 2020.lrec-1.710). 36 names per object; shows
  hierarchical and cross-classification naming variation. Phenomenon known; its effect on hallucination metrics
  across guidelines is not measured there. Moderate.
- [V] Freitag, Grangier & Caswell, EMNLP 2020, arXiv:2004.06063. Reference style changes MT metric correlations.
  The closest "references are not innocent" analogue, but for MT and n-gram metrics. Moderate.
- [V paper / U claim] Lee et al., arXiv:2412.15484 (hyper-detailed captioning). A search summary says a
  reference-based factuality score fell from Spearman 67.9 to 18.3 with stylistically different human captions.
  Not confirmed on the page. VERIFY.
- [V paper / U claim] UMIC, Lee et al., ACL 2021 short, arXiv:2106.14019: scores vary with reference type (search summary).
- [U] CHAIR: Rohrbach et al., EMNLP 2018, arXiv:1809.02156 (fixed COCO-80 synonym list).
- [U] SPICE: Anderson et al., arXiv:1607.08822 (WordNet synonyms).
- [V, partial] Vietnamese WordNet: Lam & Kalita 2022, Computacion y Sistemas. Built by MACHINE-TRANSLATING WordNets.
  If used, that is an AI-made lexical signal and must be flagged.
Overall: soft / hierarchical / embedding matching = LOW novelty. Two-panel same-image invariance audit
(kappa vs shuffled null, naming-vs-selection split, cross-gold system rank stability) = MODERATE. Two searches found
no study isolating annotation guidelines across datasets for object metrics. That is absence of evidence, not a "first".

3. EVIDENCE SO FAR (CPU, nice 19, 1 thread, < 1.5 GB, longest run 3 min)
Protocol:
- matcher = rescap.chair.objects_in (v2 tone-normalised), object_prf.image_counts/scores, pooled per image as in
  C1_ceiling/ktvic_ceiling.py;
- within = each KTVIC caption vs the union of the other 4;
- cross4 = each OpenViIC caption vs the same 4-unions (gold size matched); cross5 = vs all 5;
- null = same, against the refs of a different image (fixed derangement, seed 0);
- kappa = (cross4 - nullC) / (within - nullW);
- learned merges and pi_c are fitted on KTVIC train-minus-dev300 only;
- design choices on dev300 (300 imgs, 296 with OpenViIC);
- ONE test look (555 imgs) with the script frozen (md5 above) beforehand.

Readout:
(a) Naming layers close 28-33% of the gap on both splits (H1).
(b) Free merges by within-caption co-mention exclusivity chain everything into one class (người + xe + nhà + ...).
    Captions name ~1.7 objects, so ANY two co-present objects are mutually exclusive within a caption (salience
    competition). The gap "closes" to 4-5 only because the null rises to 75 (H5). Raw gap closure is not evidence;
    the shuffled null must be reported.
(c) pi_c does not predict cross-panel divergence: Kendall tau(pi_c, OpenViIC-unconfirmed share) = -0.04 (dev300,
    46 classes), -0.26 (test, 54). CW adds nothing over L1/L2. H4 falsified.
(d) Top dev300 unconfirmed classes (share of OpenViIC mentions outside the KTVIC union):
    dù 1.00 (14 mentions; KTVIC never says it, so a dialect synonym of ô; from the run BEFORE DIALECT was added,
    reproduce with DIALECT = {}; frozen dev300.json shows the merged class ô: u .48, n 21), bóng, sạp hàng, dãy nhà .90, biển hiệu .89, phòng .83,
    đồ .73, mũ .66 (OpenViIC names hats 3.7x as often), quần .64.
    These are scene, signage, clothing and generic nouns: selection policy.
(e) THING tier halves the remaining gap. The residual (P 62.7 vs 86.5) is plausibly clothing/accessories (mũ, quần,
    áo), which COCO-80 lacks and where full invariance holds. Hypothesis for Gemini, untested.

6. RISKS AND FIT WITH PD-2
Risks:
- Only one guideline pair. Invariance is shown for KTVIC vs OpenViIC only; no third same-image Vietnamese panel exists.
- The THING tier is a vocabulary restriction, so reviewers may call it "just COCO-80". The defence: keeping
  Vietnamese-specific things (nón lá, xích lô, xe ba gác) and reporting SCENE separately rather than dropping it.
- One exploratory test look has been taken (frozen script). Confirmatory claims must use the NEW pre-registered
  quantities (primary tier, count-matched endpoints).
- The closed 113-class lexicon makes out-of-vocabulary mentions invisible. An open-vocabulary extractor would need an
  LLM, an AI signal.
- The kappa normalisation depends on the null definition (a derangement); report the nulls too.
Fit with PD-2: strengthens the evaluation/methodology pillar directly.
- It explains why the human ceiling is 60.5 (within guideline) and 45 (cross guideline): ~30% naming, ~70% selection.
- It gives reviewers a guideline-robust object score.
- It tempers "fuse2 beats humans" claims: they become tier-specific.
- It turns the count-matched frontier into a cross-guideline test.
It is not a method that beats the count frontier.
