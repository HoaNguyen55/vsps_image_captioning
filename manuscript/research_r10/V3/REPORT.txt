R10 V3 -- A Vietnamese caption error taxonomy measured on existing outputs (rule-based, reference-derived, no AI labels)
Agent V3, 2026-10-14. Folder: research_r10/V3/ (scratchpad). Script: V3/taxonomy.py (sha256 05992fde...), output
V3/taxonomy.json (sha256 450f6c91...), table V3/table.txt (V3/show.py prints it). Run: 11 s wall, 234 MB, 1 core.

0. BOTTOM LINE
- I built a 15-class error taxonomy. It is rule-based and reference-derived, with no model and no AI label. Content
  classes: object, person-type, count, colour, size, relation, plus salient omission. Form classes: classifier slot,
  register, CJK, English, fragment, function-word end, cut-off, repeated 5-gram. I measured it on 25 KTVIC-test
  output sets (558 images each), 4 sample pools and the 35_e RL log.
- KTVIC SFT removes almost every language-form error: each form class is <= 3% of P1/fuse2 captions (one exception:
  fuse2-detailed's template repetition, 17.7%), against 25-98% for zero-shot and legacy systems. For every fine-tuned
  system the dominant error is object hallucination (P1 21%, fuse2 29% short / 52% detailed), followed by person-type
  (7.6% / 11% / 19%).
- What count-controlled object evaluation misses: 7-14% of the flagged error instances of the short fine-tuned systems,
  19-20% for fuse2 detailed, 26-35% for zero-shot and 9-71% for legacy systems. It also misses form side effects of a
  "pure count shift": MBR selection removes fragments (P1 -1.1 pp [-2.0,-0.4]) and adds CJK (fuse2 +0.7 pp [+0.2,+1.4]).
- Two defects in the object metric itself:
  (a) The CHAIR-vi hypernym lattice has no links from cô gái / chàng trai to phụ nữ / đàn ông / người. As a result,
      38% of P1's person-type "hallucinations" and 68% of zero-shot-short's are same-gender specificity mismatches.
  (b) The classifiers cây and quả are read as objects in 0.5-7% of captions.
- The KTVIC references can verify only a small part of the non-object claims. Count is checkable for about 1-4% of
  asserted count phrases, relation for <= 28%, size almost never. So count, attribute and relation errors need
  independent human labels: the existing COCO instance counts. That is the pilot.
- Novelty is moderate-low for a taxonomy. AMBER, CHAIR and van Miltenburg & Elliott already cover the content classes.
  What is new: Vietnamese form classes, a blind-spot audit of a count-matched endpoint, and coverage per claim type.
  Expected value: one appendix table plus a matcher fix for the PD-2 evaluation pillar, not a headline.

1. PROBLEM AND HYPOTHESES
Problem. The PD-2 primary endpoint compares object sets at matched object count. By construction it sees only object
classes. It cannot see wrong counts, colours or relations, classifier misuse, off-register text, script leakage or
truncation, and it inherits whatever its matcher gets wrong. How large is that blind spot, and which error class
dominates each system? This can be measured on existing files only.

Falsifiable predictions for the pilot (section 4). The observed values below come from this run.
- H1 (count-flag validity): against COCO instance counts (existing human labels), the strict reference-derived count flag
  has precision >= 0.70 for person and vehicle classes with <= 5 instances; the lenient flag has precision < 0.50.
  Refuted if strict precision < 0.50.
- H2 (lattice fix): adding the missing person links (matcher v3) raises object P and lowers CHAIR_i for every system,
  more for zero-shot than for P1. It does not break the pre-registered count frontier: invariance still holds.
  Refuted if |dP| < 0.2 pp for all systems, or if the zero-shot gain is <= P1's gain.
- H3 (form side effects of selection): MBR/UPE selection lowers the fragment rate on dev300 (CI excludes 0 in >= 2 of 3
  seeds), although its count-matched dF1 is about 0 (UPE kill 2 fired).
- H4 (RL): CN-RLOO vs P1_dev on dev300 does not raise fragment, fw_end, register, CJK or English incidence (each CI
  includes 0 or lies below 0). Refuted if any one of them rises with its CI above 0.

2. CLOSEST PRIOR WORK (IDs verified by web search on 2026-10-14 unless marked)
- Rohrbach et al., "Object Hallucination in Image Captioning", EMNLP 2018, arXiv:1809.02156 (ACL D18-1437). Defines CHAIR:
  object-only and English. Here: CHAIR-vi is reused as the object class, and 13 non-object classes are added.
  Novelty vs this paper: moderate.
- van Miltenburg & Elliott, "Room for improvement in automatic image description: an error analysis", arXiv:1704.04198
  (2017). A manual error taxonomy of an English captioner. Here: fully automatic, Vietnamese, with
  references used as the only judge. Novelty: moderate.
- Shekhar et al., "FOIL it!", ACL 2017 (P17-1024), arXiv:1705.01359. Single-word foil errors in captions, built
  synthetically. Here: errors are found in real system outputs. Novelty: high relative to FOIL, but FOIL's aim differs.
- Wang et al., "AMBER: An LLM-free Multi-dimensional Benchmark for MLLMs Hallucination Evaluation", arXiv:2311.07397.
  The closest prior work: LLM-free, with existence, attribute and relation classes, but it needs dedicated annotations.
  Here: no new annotation, the language-form classes are added, and evaluability coverage is reported.
  Novelty vs AMBER: low-moderate.
- Wu et al., "Evaluating and Analyzing Relationship Hallucinations in LVLMs" (R-Bench), ICML 2024, arXiv:2406.16449.
  Relation hallucination needs targeted questions. This run shows that the KTVIC references cannot score relations:
  0 contradictions at <= 0.10 evaluable relations per caption. Novelty: low.
- Guan et al., "HallusionBench", CVPR 2024, arXiv:2310.14566. VQA-style diagnosis of language hallucination and visual
  illusion. It does not taxonomise free-form captions. Novelty vs it: high, but the problem is different.
- Dong et al., "Benchmarking and Improving Detail Image Caption" (CAPTURE), arXiv:2405.19092. Extracts objects,
  attributes and relations with a scene-graph parser, for English, with no form classes. Novelty: moderate.
- Zhai et al., "HallE-Control / CCEval", arXiv:2310.01779. Controls detail level when measuring hallucination, using a
  GPT-4-assisted judge. This is the closest idea to "matched count", but it uses an AI judge.
  Novelty: moderate (here no AI judge, and the blind-spot audit is new).
- Marchisio et al., "Understanding and Mitigating Language Confusion in LLMs", EMNLP 2024, arXiv:2406.20052.
- Hinck et al., "Why do LLaVA VLMs Reply to Images in English?", Findings of EMNLP 2024, arXiv:2407.02333.
  Both papers measure wrong-language output. Here: the same failure, inside captions, as CJK and English classes
  on an SFT captioner. Novelty: low-moderate.
- Qu et al., "Mitigating Multilingual Hallucination in LVLMs", arXiv:2408.00550. A multilingual extension of POPE
  (VQA), not caption errors. Seen in search only, details unverified: CLAIM (ACL 2025, arXiv:2506.11073).
- Bai et al., "Hallucination of Multimodal LLMs: A Survey", arXiv:2404.18930. Its category/attribute/relation taxonomy
  was NOT confirmed in the snippets I saw: verify before citing it for that.
Overall novelty: MODERATE-LOW. The content classes are standard. Novel here: (i) Vietnamese form classes (classifier
slot, register measured against reference rates, CJK, English, function-word ending), all scored by one AI-free
instrument; (ii) a quantified blind spot of a count-matched object endpoint, per system; (iii) evaluability coverage
reported for each claim type.

3. EVIDENCE SO FAR (CPU, existing files only; KTVIC test, 558 images; incidence = % of captions with >= 1 error)
Instrument. All norms come from the 17,345 KTVIC train references outside dev300 (the vi_diagnostics convention):
- the 848 syllables that end some reference;
- classifier-slot usage after a numeral or quantifier;
- register-marker rates: an a-priori marker is used only if < 0.5% of references contain it, so "bức ảnh"
  (3.6%) and "khung hình" (0.9%) are excluded;
- the Vietnamese syllable inventory.
English tokens are pure-ASCII words that are absent from KTVIC train and present in COCO-EN captions; loanwords
(jeans, led, cafe...) are counted separately. Reused code: rescap.chair (objects_in, the gold lattice),
vi_diagnostics.syllables, clean_supervision (CJK_RE, repeated_ngram n=5) and rl_reward.FUNCTION_END.
Reference rules:
- count: a caption numeral is contradicted only when >= 2 references state an explicit total (>= 2) for the SAME noun
  and none of them agrees (strict rule); collectives such as cặp đôi are excluded;
- colour: hue sets per noun, with neighbouring hues counted as agreement, so colour errors are a lower bound;
- size and relation: an antonym in a reference for the same noun or pair, and no reference agreeing.

  3. A claim is "instance-wrong" if n (1-5) differs from the non-crowd instance count with area >= 1% of the image.
  4. Report the precision and recall of the strict and lenient flags against instance-wrong claims, with a bootstrap
     CI over images.

6. RISKS AND FIT WITH PD-2
Risks:
- No human validation of rule precision is allowed beyond existing labels. P-A covers count only; the register,
  classifier and English rules are audited only by listing their top flagged items (taxonomy.json:
  top_register, top_cl_pairs, top_english).
- The classifier rule still fires on lexical compounds ("quả cầu" = globe), so treat the class as an upper bound.
- The object class inherits reference incompleteness: R9 C3 found 56.5% of P1's object false positives are real.
- repeat5 counts template reuse as well as genuine loops.
- Coverage is tiny for count and relation, so low error rates there mean "unmeasurable", not "rare".
- The cut-off rule is undefined for unpunctuated systems (P1, fuse2 short).
Fit: this strengthens the evaluation/methodology pillar in three ways:
- (i) It gives a measured scope statement for the count-matched endpoint: what it cannot see, per system.
- (ii) A one-file matcher fix (v3 lattice) that may shift the CHAIR and object numbers. The zero-shot-vs-P1 comparison
  is the most exposed.
- (iii) Evidence that SFT solves language form, which justifies centring the paper on object content.
It adds no method that beats the count frontier.
