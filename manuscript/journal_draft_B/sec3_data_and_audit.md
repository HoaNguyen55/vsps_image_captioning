## 3.2 The five references of an image come from one writer

KTVIC's paper describes an interface in which one annotator types all five captions of an image (Pham et al., 2024, §3.2, Fig. 5). Metrics built on multiple references assume that the references are independent descriptions. We test the assumption directly with an exchangeability statistic on object mentions. Take every object class that exactly two of an image's five references name (a "doubleton"). If the five slots were exchangeable, the two naming references would be adjacent (slots *i* and *i*+1) with probability 4/10 = 0.40.

On the test split the observed adjacent share is 0.7102 [0.6696, 0.7518] over 566 doubletons (z = 15.07 against the null of 0.40)<!-- src: .session_backup/2026-10-14/r11_verify/c3_n2_exchangeability_all_datasets.json :: k5_exchangeability_audit.ktvic_test_objects_in.adjacent_share ; adjacent_share_ci95 ; total_doubletons ; adjacent_share_z_vs_null ; adjacent_share_null -->. The training split shows the same pattern, 0.6673 [0.6499, 0.6852]<!-- src: .session_backup/2026-10-14/r11_verify/c3_n2_exchangeability_all_datasets.json :: k5_exchangeability_audit.ktvic_train_objects_in.adjacent_share ; adjacent_share_ci95 -->, as does dev300, 0.631 [0.5649, 0.6962]<!-- src: .session_backup/2026-10-14/r11_verify/c3_n2_exchangeability_all_datasets.json :: k5_exchangeability_audit.ktvic_dev300_objects_in.adjacent_share ; adjacent_share_ci95 -->. Object-set similarity between consecutive references (lag 1) exceeds the mean similarity at lags 2–4 by 0.135 [0.1178, 0.1538] in Jaccard index<!-- src: .session_backup/2026-10-14/r11_verify/c3_n2_exchangeability_all_datasets.json :: k5_exchangeability_audit.ktvic_test_objects_in.jac_lag1_minus_mean_lag2to4 ; jac_diff_ci95 -->. The pattern is consistent with the single-writer interface: a chain of paraphrases, each written with the previous one in view. A trend over slot positions alone could also raise both statistics, since slot 0 names fewer objects than later slots (Section 4.1). A permutation null that keeps each slot's inclusion rate would separate the two explanations; we have not run it, so the slot-position explanation is not excluded. A share above 0.40 is also not by itself specific to a single writer. The statistic is defined in the companion paper, which reports it on other corpora: two caption sets written by independent annotators with a documented protocol, COCO and UIT-ViIC, sit at the null there, while Flickr30k, also written by independent workers, sits above it, which the companion attributes to a non-random file order, and so does the full UIT-OpenViIC test, whose caption-entry protocol is undocumented. The companion in turn leaves the KTVIC case to this paper, so the contrast between KTVIC and the other corpora is split across the two papers, and neither shows it alone. KTVIC's share is well above every value the companion reports, and the KTVIC paper documents the single-writer interface, but the step from the statistic to "one writer" rests on that documentation, not on the statistic alone.<!-- R2 N-M4 (circular controls disclosed, no companion values printed: PD-6) and N-M5 ("at the null on corpora written by independent annotators" was wrong: companion journal_draft/sec5_exchangeability.md Table 5.1 and :33-36 put Flickr30k and OpenViIC full test above the null). --><!-- Figure slot (main, 2026-10-19): place B2's B-only adjacency figure here (.session_backup/2026-10-18/paperA_tasks/B2/fig2_adjacency_Bonly.pdf), never the variant with Paper-A comparators (PD-6). Insert only after the A-verifier marks B2 VERIFIED; until then no B2 number enters the text. -->

Two consequences follow for evaluation.

- **The references are one writer's view, five times.** A leave-one-out comparison of each reference against the other four gives object P / R / F1 of 85.33 / 46.90 / 60.50<!-- src: data/results/human_parity.json :: 1v4.human.P ; 1v4.human.R ; 1v4.human.F1 -->. Because all five references share one writer, this is a within-writer consistency figure, not a human ceiling; we do not compare systems to it as "human parity".
- **Five references are worth less than five.** The object gold of an image is the union of its references. Under a chain of paraphrases, the extra references add fewer new objects than independent captions would, so recall against the union understates what a caption gets right about the image. Section 5.3 measures this with a second caption panel.

## 3.3 No punctuation in the references, and what one period costs

None of the 2,790 test references and none of the 18,845 training references ends with a period<!-- src: .session_backup/2026-10-14/r11_verify/c1_b1_b6_reproduction.json :: B5_L5_cider_punct_and_uitviic_chair.ktvic_period_audit.test_refs_ending_period ; train_refs_ending_period -->. A system fine-tuned on KTVIC learns this: none of the 558 test outputs of P1-R (seed 42) ends with a period, while 557 of the 558 zero-shot outputs of the same backbone do<!-- src: .session_backup/2026-10-14/r11_verify/c1_b1_b6_reproduction.json :: B5_L5_cider_punct_and_uitviic_chair.ktvic_period_audit.p1assist_s42_short_ending_period ; zeroshot_short_ending_period -->.

**Mechanism.** CIDEr-D weights each n-gram by its inverse document frequency over the reference set and divides the dot product by the norms of the candidate and reference vectors. An n-gram that contains "." has document frequency zero in KTVIC's references. It cannot match, but it still enters the candidate's norm, so every period lowers the score of the whole caption.

**Size.** Appending one "." to each output of P1-R (seed 42) lowers CIDEr-D from 148.66 to 113.49 against the five references, a change of −35.17 (−23.66%)<!-- src: .session_backup/2026-10-14/r11_verify/c8_l5_d1_d3a_cpu_audit.json :: l5_d1_punct_idf_law|ktvic_test_k1_to_k5_curves|p1assist_s42-short|first_k|k=5|cider_strip ; cider_add_period ; d_abs ; d_rel_pct -->. Against one reference the change is −36.17 (−16.73%)<!-- src: .session_backup/2026-10-14/r11_verify/c8_l5_d1_d3a_cpu_audit.json :: l5_d1_punct_idf_law|ktvic_test_k1_to_k5_curves|p1assist_s42-short|first_k|k=1|d_abs ; d_rel_pct -->. The absolute loss stays near 35 points as references are added, while the relative loss grows, because the score itself falls with more references. In the other direction, the zero-shot outputs score 28.98 as written and 33.30 with their final periods stripped<!-- src: .session_backup/2026-10-14/r11_verify/c8_l5_d1_d3a_cpu_audit.json :: l5_d1_punct_idf_law|ktvic_test_k1_to_k5_curves|zeroshot-short|first_k|k=5|cider_add_period ; cider_strip --> (the committed score is 28.98<!-- src: data/results/zeroshot-short.json :: results[0].scores_scaled_x100.CIDEr -->). Part of the gap between zero-shot and fine-tuned systems on KTVIC is therefore punctuation, not content.

**UIT-ViIC follows the opposite convention.** Its references almost all end with a period: 1,133 of its 1,155 test references (98.10%)<!-- src: .session_backup/2026-10-18/cpu_audit_r15/xm3600_period_cider_decomposition_v1.json :: reference_punctuation_audit.uitviic_test_231.raw_end_period_count ; n_refs ; raw_end_period_rate_pct (raw string count, no segmentation; recounted independently from data/datasets/uitviic/test_data.json, WRITER_B_LOG.md) -->. ## 3.5 Object matchers v1, v2 and v3

Object-level scores (CHAIR, object precision and recall) need a matcher that maps Vietnamese words to object classes. We describe three versions and state which one each number uses; the kit releases v1 and v2.

- **v1** is the 113-entry Vietnamese lexicon of the FAIR version, applied to raw text.
- **v2** adds tone-mark normalisation: the two placements of the tone mark in syllables such as *hoà/hòa* map to one form. v2 is the primary matcher of this paper. Normalisation changes none of the 2,790 KTVIC test references<!-- src: data/results/tone_norm/SUMMARY.json :: reference_invariance.ktvic_test_2790.m1_changed -->; it changes the matched objects of 30 of the 73 KTVIC systems covered by the tone-normalisation rescoring (an inventory compiled separately from the 79 systems of the ranking audit in Section 5.3)<!-- src: data/results/tone_norm/SUMMARY.json :: meta.ktvic_systems_with_any_change ; meta.ktvic_total_systems -->, because some outputs use the other tone placement.
- **v3** adds rules for classifier nouns, compounds and role nouns. *Cây* is both the noun "tree" and the classifier for long objects (*cây cột* "pole", *cây xăng* "petrol station"), and *cầu* in *cây cầu* is "bridge". Of 980 *cây* tokens the matcher extracts from the training references, 210 are classifier uses and 160 are *cây cầu*<!-- src: .session_backup/2026-10-13/tone_norm/cay_audit.json :: references.ktvic_train_refs.emitted_cay_tokens ; classifier_cay_tokens ; cay_cau_tokens -->. v1 and v2 count all of them as the class "tree". **The v3 rules were drafted by an AI model (one of the coding assistants of Section 7.4) from training-split counts and have no human sign-off.** We therefore report v3 only as a sensitivity analysis, draw no conclusion that depends on it, and do not include its rules in the kit.

The choice matters for absolute values and little for comparisons. For P1-R (seed 42), v3 lowers the number of mentioned classes per caption from 1.823 to 1.706 and raises object F1 from 55.51 to 56.95<!-- src: .session_backup/2026-10-13/r10_cpu/v1_v3_unified_v3_audit_v3.json :: part1_unified_v3_sensitivity.ktvic_test558_systems.p1assist_s42-short.v2.M ; v3.M ; v2.F1 ; v3.F1 -->. The within-writer leave-one-out F1 moves from 60.50 to 61.67<!-- src: .session_backup/2026-10-13/r10_cpu/v1_v3_unified_v3_audit_v3.json :: part1_unified_v3_sensitivity.human_1v4_ktvic_test.v3.macro_by_fold.F1 -->. The frontier exponent used by the supervision ladder (Supplementary S2) is 0.7468 under v2 and 0.7470 under v3<!-- src: .session_backup/2026-10-13/r10_cpu/v1_v3_unified_v3_audit_v3.json :: part1_unified_v3_sensitivity.frontiers_ktvic_test.v2.b_anchor_p1_to_fuse2det ; v3.b_anchor_p1_to_fuse2det -->.

On UIT-ViIC, role and child nouns (*đứa trẻ* "child", *đàn ông* "man") dominate the hallucinations counted against COCO classes. A separate role/child canonicalisation, also without human sign-off, lowers CHAIR_i of the KTVIC-trained P1 (legacy mask, seed 43) from 30.02 to 21.39 but of the zero-shot system only from 27.12 to 26.01<!-- src: .session_backup/2026-10-14/r11_verify/c5_n11_uitviic_role_child_audit.json :: uitviic_test.v2.transfer_p1_s43-short.CHAIR_i ; uitviic_test.v3_role_child.transfer_p1_s43-short.CHAIR_i ; uitviic_test.v2.zeroshot-short.CHAIR_i ; uitviic_test.v3_role_child.zeroshot-short.CHAIR_i -->. ## 3.6 Image overlap with other datasets

KTVIC and UIT-OpenViIC draw on a shared image pool and split it independently. Of the 558 KTVIC test images, 555 match an image somewhere in UIT-OpenViIC (Section 3.1), and 401 (71.86%) match an image in the OpenViIC training split<!-- src: .session_backup/2026-10-13/r10_cpu/r10_a1_a3_spotchecks_v2.json :: A_32_leakage_disclosure.splits.ktvic_test_558.in_openviic_train ; in_openviic_train_pct -->. **How images are matched.** A pair is proposed when the 64-bit perceptual hashes of two images (pHash or dHash, also computed on the mirrored KTVIC image) differ in at most 10 bits, and confirmed when the SSCD copy-detection descriptors (Pizzi et al., 2022) of the two images have a cosine similarity of at least 0.5<!-- src: scripts/match_openviic.py (archived) :: argparse defaults --hash-max 10 ; --sscd-min 0.5 ; module docstring "Matching" -->. Sampled matched and borderline pairs were inspected visually; we have not estimated false-match or missed-match rates, so 401 and 555 are counts under this rule, not verified totals. The matcher needs the public SSCD model, which the reader obtains separately (Section 3.7).<!-- R2 N-M9 -->

No model in this paper is trained on OpenViIC: every fine-tuned model was trained on KTVIC train only<!-- src: .session_backup/2026-10-19/HV_LK/b_n2/b_n2_inventory.json ; manuscript/GAP_ANALYSIS_Q1Q2_2026-10-19_ERRATA.md -->. ## 3.7 The evaluation kit and data availability

The audits in this section are the paper's reusable contribution. We release them as an evaluation kit: our own code and documentation, a template for the protocol card, the pre-registration files, score-only copies of the result files the numbers manifest cites (caption fields removed for licensing; each original file's SHA-256 is given) and the manifest itself. Each script runs on the reader's own copy of the datasets and on the reader's system outputs; the XM3600 audit names the paper's six runs, and the reader edits those names to audit other systems. The kit contains our matcher word lists (author-built, v1 and v2) but no counts derived from KTVIC and no dataset captions; the model-drafted v3 rules are not included.
