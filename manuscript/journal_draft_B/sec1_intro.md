Public Vietnamese image-captioning benchmarks include UIT-ViIC (Lam et al., 2020), KTVIC (Pham et al., 2024) and UIT-OpenViIC (Bui et al., 2026), with further sets for narrower domains (Section 2). Systems are compared on them mainly by CIDEr. On KTVIC a fine-tuned vision–language model (VLM) now scores far above the reported transformer baseline. Our response-only fine-tune of Qwen2.5-VL-7B reaches a word-level CIDEr-D of 148.23 (SD 0.38 over three seeds)<!-- src: .session_backup/2026-10-15/paperA_keys/cider_3seed_mean.json :: mean ; sd_sample_ddof1 -->; GRIT is reported at 136.0<!-- src: literature: FAIR 2026 Table I (GRIT as reported for KTVIC); protocol not matched -->. Gaps of this size invite a leaderboard reading. This paper asks a prior question: what does a KTVIC CIDEr score measure, and how much of a difference between two systems is about the image?

We answer with an audit of the dataset, run with a controlled system as the measuring instrument, and we release the audit as an evaluation kit. Four properties of KTVIC change the answer.

1. **The five references of an image come from one writer.** The KTVIC annotation interface asks one annotator to enter all five captions of an image, with three annotators in total (Pham et al., 2024, §3.2, Fig. 5). The references are therefore not independent draws. Of the objects named by exactly two references, a share of 0.7102 [0.6696, 0.7518] sit in adjacent slots, against 0.40 if the order were exchangeable<!-- src: .session_backup/2026-10-14/r11_verify/c3_n2_exchangeability_all_datasets.json :: k5_exchangeability_audit.ktvic_test_objects_in.adjacent_share ; adjacent_share_ci95 ; adjacent_share_null -->.
2. **The references contain no sentence-final punctuation.** None of the 2,790 test references ends with a period<!-- src: .session_backup/2026-10-14/r11_verify/c1_b1_b6_reproduction.json :: B5_L5_cider_punct_and_uitviic_chair.ktvic_period_audit.test_refs_total ; test_refs_ending_period -->. Zero-shot outputs, which end with a period, gain from 28.98 to 33.30 CIDEr-D when the period is stripped<!-- src: .session_backup/2026-10-14/r11_verify/c8_l5_d1_d3a_cpu_audit.json :: l5_d1_punct_idf_law|ktvic_test_k1_to_k5_curves|zeroshot-short|first_k|k=5|cider_add_period ; cider_strip -->. In the other direction, appending a single "." to every output of our fine-tuned system lowers CIDEr-D by 35.17 points (−23.66%)<!-- src: .session_backup/2026-10-14/r11_verify/c8_l5_d1_d3a_cpu_audit.json :: l5_d1_punct_idf_law|ktvic_test_k1_to_k5_curves|p1assist_s42-short|first_k|k=5|d_abs ; d_rel_pct -->. Any system that writes ordinary Vietnamese sentences pays this cost.
3. **Object scores depend on an undocumented matcher.** Tone-mark normalisation, classifier nouns such as *cây* and role nouns change which objects a caption "mentions". We document three matcher versions. Only v1 and v2 are attested; v3 is a model-drafted rule set without human sign-off, so we report it as sensitivity only.
4. **Two caption panels disagree.** Of the 558 KTVIC test images, 401 (71.86%) also appear in the UIT-OpenViIC training split, and 555 appear somewhere in UIT-OpenViIC, with independent captions<!-- src: .session_backup/2026-10-13/r10_cpu/r10_a1_a3_spotchecks_v2.json :: A_32_leakage_disclosure.splits.ktvic_test_558.in_openviic_train ; in_openviic_train_pct ; total_in_openviic_panel -->. Scored against that second panel (aggregates only), some differences between systems shrink or vanish.

**Contributions.**

- *A dataset-validity audit of KTVIC* (Section 3): single-writer references, the punctuation convention and its effect on cross-corpus CIDEr, segmentation sensitivity, matcher versions, and image overlap with UIT-OpenViIC and COCO, with a second caption panel on the same images (Section 5).
- *A protocol card* (Section 4.2) that names segmenter, CIDEr variant, scale, punctuation handling and matcher for every score, applied to a controlled system whose committed scores a second machine reproduces byte for byte.
- *An evaluation kit* (Section 3.7): the scorer and protocol card, the matcher code, the split and overlap scripts and the audit scripts, under an open-source licence. The n-gram scoring, the punctuation and segmentation audits, the exchangeability test and the overlap check run as shipped on a new system or dataset; the object-level audits also need a matcher lexicon, which the kit does not include until the dataset terms are settled. The kit contains only our own code and documentation and redistributes no dataset text.

**Relation to earlier work.** A conference version (Nguyen et al., 2026b) introduced VSPS, which builds supervision for detailed Vietnamese captioning from verified propositions. It reported the P1 gold-SFT control on KTVIC (seed 42) as a baseline. None of this paper's primary results appear there. The overlap is the KTVIC/COCO setup, the P1 training recipe and the P1 seed-42 score, which we reuse as a reference point. A companion paper (under review) studies when object-level hallucination scores support a comparison between systems: how the completeness of the gold and the number of mentioned objects drive them, on English and Vietnamese sets including XM3600 and UIT-ViIC. It uses KTVIC only as a motivating example, but it scores outputs of this paper's KTVIC-trained systems on XM3600 and of its ten UIT-ViIC systems, for its own claims about gold completeness. Table 7.1 lists what each paper claims and which data it uses; no number is a primary result in both.

**What we do not claim.** We claim no state of the art on KTVIC: no published Vietnamese system has been rescored under our protocol, and GRIT's 136.0 comes from a different protocol. We make no claim about human judgments of caption quality, because no new human annotation was collected. Model-generated labels and votes serve only as method components, never as evidence.
